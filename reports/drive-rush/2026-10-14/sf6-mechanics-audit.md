## 直接纠正与后续确认

用户已明确：普通Parry及Perfect Parry成功后的退出不再一律追加12f；仅紧接成功的退出免后摇，继续空持后再松手恢复12f。设计第6.1节已记录。后摇期间普通方向防御仍不是蓝防成功，不提前解除后摇。

**后续已确认（2026-10-14）**：用户回复“可以”，采用设计第6.1节的统一6f成功退出窗口、成功退出可越过最短持续、不增加成功硬直的方案。成功帧S至S＋5内松手免12f，S＋6起过期；继续空持不永久免后摇；新的有效成功重新提供窗口，无敌期间的无效命中不刷新。既有6f／10f成功反馈动画不代表操作硬直，也不自动充当退出窗口。这是以撒适配规则，不是街霸原版固定6f窗口。

原版成功招架免空挥收招不等于全程零硬直：普通成功招架保留被防招式的防御硬直；近身Perfect Parry有画面停顿并留下1f恢复；飞行道具Perfect Parry无该画面停顿，官方列10f恢复，连同发生帧为11f。不能据此把以撒所有成功招架写成必须再站12f，也不能把普通与完美招架完全等同。

## 玩法差异

| 项目 | 街霸6 | 以撒当前确认 |
| --- | --- | --- |
| 蓝防移动 | 持续招架姿态本身不能自由步行 | 蓝防仍可自由移动；只有需要后摇时固定脚步 |
| 招架范围 | 通常打击与飞行道具可招架，投技克制招架；普通防御按上下段、左右判定 | 普通防御按来源／来向±45°；接触、激光、地板、无来源被排除；蓝防可挡这些，炸弹和生命代价除外 |
| 近身完美条件 | 首2f且正确站／蹲防方向；飞行道具不需要该方向条件 | 统一首3f，无额外方向条件，不区分近身与飞行道具 |
| 普通招架回气 | 飞行道具通常0.5格，普通／特殊技等通常1格，超必杀／DI通常2格，多段按规则分配 | 每次有效普通蓝防统一0.5格 |
| 完美收益 | 主要提供反击机会；通常按被防招式回气，不直接回满；反击有50%伤害修正 | 回满6格，并给一次满蓄力与3秒射速达到4.0；没有该反击减伤 |
| 成功后的保护 | 多段攻击按招架／硬直规则处理，完美有其独立短保护 | 所有成功防御均给予原生对应受伤无敌时间，期间其他无效命中不扣费、不回气 |
| 绿冲路线 | 向前突进，角色之间的速度／距离不同；不是二维自由转向 | 任意方向／斜向、15°每帧转向、反向刹车；初始方向半房间总路程 |
| 绿冲攻势收益 | 通常技获得额外4f命中／防御优势等属性；存在攻击取消绿冲路线 | 采用满蓄力＋射速奖励；没有3格攻击取消绿冲路线 |
| 绿冲中被打 | 反击命中规则，有反击伤害／硬直属性，不是统一2倍伤害 | 只有实际扣血时中断并2倍伤害；普通防御或护盾挡住继续冲 |
| 防御扣气 | 各招式各自指定斗气伤害，不与生命伤害固定同比例 | 半心1格，一心2格；余额不足时仍能防最后一击 |
| 回气来源 | 时间、向前走、命中／被防／被招架等；部分行为后存在额外回气冷却 | 时间＋任意方向有效主动行走；击杀1格，命中不回；只按既定状态暂停，无动作后额外冷却 |
| 普通自然回复 | 社区表常态0.24格／秒，力竭0.30格／秒；受创等状态另有倍率 | 常态0.10格／秒，力竭0.30格／秒 |
| 行走回复 | 前走额外回气，持续前走还有阶段性增强；非单一全程＋50% | 任意方向有输入且实际行走统一＋50%；贴墙不动无加成 |
| 力竭 | 禁用斗气动作，仍可普通防御；增加4f防御硬直、特殊技／超必杀削血、角落DI可致晕 | 普通防御失效、伤害×0.75、射速×0.75；没有防御硬直／墙角晕眩系统 |
| 低斗气发动 | 多数斗气动作可透支；蓝防首帧与扣费时点会形成极端例外，不能笼统等同 | 蓝防≤0.5格无有效窗口；绿冲不足额外0.5格失败，恰好付清至0可完成本次 |
| 持续与清算 | 对战回合规则 | 玩家随局保存斗气与力竭；重新获得不回满、离身冻结；这是道具持有规则 |

这些差异大多来自用户已经逐项确认的改编，不能在“仿照街霸”的检查中擅自替换。尤其3f完美、满气奖励、击杀回气、力竭双0.75与普通防御失效、2倍绿冲受伤、自由转向均保持原值。普通自然回复与动作后回气冷却属于明显差异，应如实展示，不把本项目数值写成街霸原数值。
