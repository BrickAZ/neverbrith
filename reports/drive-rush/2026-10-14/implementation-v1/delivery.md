## 进入游戏测试

1. 完整退出再启动游戏，让新增 XML 注册生效。进入普通新局。
2. 控制台输入 `driveglove give`，给当前第一名玩家拳套；也可 `giveitem c797`，但运行时 ID 会随其他 Mod 的加载变化，以 `driveglove give` 为准。
3. `driveglove status` 输出斗气、力竭、动作、已移动帧、剩余路程和奖励状态。
4. `driveglove meter 0` 用于快速试力竭；`driveglove meter 6` 用于测试时恢复。它们是调试命令，正常游戏恢复仍按机制执行。

| 操作 | 当前行为 |
| --- | --- |
| 朝攻击飞行方向输入移动，或远离其他可防御来源 | 0f 普通防御，±45°，每半心扣 1 格，可透支最后一击 |
| 按住拳套使用键，默认空格；口袋主动用相应键 | 蓝防启动扣 0.5，每逻辑帧扣 0.01；允许行走，禁止射击 |

| 空挥松手或成功窗口过期再松手 | 满足最短 6f 后进入 12f 后摇：3f 撤光、6f 收招、3f 复原；只允许普通方向防御 |

| 已移动 4f 后输入当前后方 ±45° | 刹车；边界 135° 算反向 |

固定速度 `260/18`，水平预算 260、垂直 140、45°约 198；转弯不刷新距离。沿用通行能力，碰到无法通过的障碍停止。正常结束和刹车没有额外蓝防后摇。

## 已接入的内容

- 独立 6 格斗气；本局首次获得满槽，同局移除再获得保留。普通自然回气 0.10 格/秒，实际行走 0.15；力竭分别 0.30、0.45。击杀回 1，命中不回；动作期间暂停时间恢复。实际行走同时要求输入、位移、方向一致且没有原生击退倒计时。
- 普通防御排除接触、激光、地板、无来源和生命代价；蓝防排除炸弹与生命代价。早期取消原生伤害，防御先于其他护盾；使用原生伤害冷却，不以弹幕实体永久去重。
- 绿冲只有实际生命减少才中断。晚期原地修改伤害值为两倍，无递归补打一遍伤害；防御按正常伤害计费，护盾挡住继续冲刺。现有七咒之戒的伤害乘数纳入普通防御费用。
- 力竭伤害、射速均乘 0.75；立即撤销奖励，满槽解除。离身冻结回复，已有力竭惩罚保留。已经支付足额、恰好用尽斗气的绿冲仍完成。
- 射速下限奖励为 4.0，首次实际发射起计 90 个逻辑帧；已经高于 4.0 不降速。蓄力只填当前武器一次；重复奖励保留最早一次。武器切换不重新赠送，读档不新增动作或奖励恢复机制。
- 当前角色与服装残影、蓝绿光效、三类防御成功反馈、12f 灰蓝残弧及收招姿态、60×8 HUD。HUD 低于 3 格褐色，力竭灰白、EMPTY 和锁定提示；射击奖励不另加视觉图标。
- 双语名称、拾取短句、EID。品质 0，默认解锁；宝箱房/贪婪宝箱房权重 1，商店/贪婪商店权重 0.5。普通主动电量不参与斗气结算。
- 本地 ID 65，追加注册；死亡/菜单图集第 65 格为已采用的 16×16 草图，其他格的 RGBA 像素与本轮基线一致。

## 待人工验收与技术边界

1. 普通/飞行/变形角色、服装层级及镜面房的画面，四人生命 HUD、多排生命和 HUD 偏移。现有角色完整保留，运行时姿态以原生缩放/倾斜适配；原型的普通以撒身体图片没有覆盖其他人物。
2. 手柄连续角度、急弯、墙边刹车、不同形状房间、沙坑/障碍；自动探针已验证固定速度和时点，仍需实际手感反馈。
3. 复杂武器联动、模组自定义武器、被动自动射击、蓄力中切换形态，以及中途力竭时的原生队列。基础武器满蓄力公式已核对，不能据此宣称所有组合都通过。
4. 原生特殊角色、特殊伤害/无敌来源、其他 Mod 在伤害回调后追加的倍率或生命价格。早期防御按可识别的原生修正计算费用，不能通用预执行其他 Mod 的任意晚期伤害回调。
5. 跟班/毒/燃烧的复杂来源链和多人最终击杀、正常退出后继续、复活/变身、书包与口袋主动。代码已接入对应流程；自动覆盖与人工确认分列在测试卡。

持续伤害存在一个已确认的第一版限制：原生后续毒伤会丢失来源。普通带毒／燃烧攻击可通过攻击自身标记追踪，带毒泪弹已原生通过；纯脚本`AddPoison`直接施加、没有攻击链可记录的来源，以及不同玩家同时施毒和燃烧而最后伤害无法区分的情况，当前不发击杀回气。不会用最后一次普通命中者冒充施加者。这是归属覆盖的技术缺口，尚未完全满足所有持续伤害归属情形。

这些是第一版测试范围，现有已确认机制没有改成新的平衡规则。音效仍为用户暂缓项。

独立代码审查发现的口袋误触发和普通命中改写施毒者两项问题已修复，新增对应回归；详见[审查记录](review.md)。最终文件校验清单见[source-sha256.json](source-sha256.json)，图集与文档链接核对见[integrity.json](integrity.json)。
