### 神的左手，恶魔之右手

| 待定项 | 建议采用的规则 |
| --- | --- |
| 目标资格、主动、自身、复制品、重复次数 | 只复制仍持有的正常被动或跟班；排除主动、自身和本效果产生的临时份数。先锁定最后一次正常获得且仍持有的道具；如果它不合格，本次使用失败，不跳过它改选更早的道具。多次使用可复制同一原物，不额外设置次数上限。 |
| 失败与充能 | 没有合法目标或授予失败，不扣充能；成功授予一份临时道具时扣 3 充能。 |
| 一次性拾取收益、不可叠加效果 | 复制品不重复发放一次性拾取资源；不可叠加道具仍可取得临时份数，其效果遵循该道具自身规则，不创造额外叠加效果。已经由实际使用产生的消耗、掉落、伤害等衍生结果不在下层倒扣。 |
| 失去原物、失去本主动、重骰 | 失去原物或本主动，不提前清除尚存的复制品。临时副本被移除后终止对应记录；副本被重骰成其他道具时，替代品仍保持本层临时身份，下层清理，不能变成永久收益。正常份数必须与临时份数分别跟踪。 |
| 死亡、复活、换层、存读档、沙漏、合作 | 同一局死亡后复活保留本层副本；实际进入新楼层时统一清理，维度或同层房间切换不算新层。续局恢复；沙漏随相应房间状态回退；按实际持有角色分别归属，合作玩家互不清理对方正常道具。 |
| 背包联动 | 本版继续复制最后获得的道具，保留原设计；不改成手动选目标。背包的接入不成为本道具的前置。 |
| 视觉与复制标识 | 图标采用一明一暗的双手及半透明复制物，保持项目现有像素风格；临时复制成功给出目标名和本层临时提示。 |

### 背包选择系统

| 待定项 | 建议采用的规则 |
| --- | --- |
| 打开入口与第一批操作 | 由需要目标的功能调用通用选择接口；提供开发调试入口验证打开、选择、取消与返回目标。常规玩法不增加免费复制／删除／重骰菜单；首批不改变神的左手的既定目标规则。具体新玩法调用者后续独立接入。 |
| 键盘、手柄、暂停 | 用当前玩家的方向／菜单导航选择，菜单确认键确认、菜单返回键取消。选择期间屏蔽该玩家的移动和攻击输入；游戏继续运行，其他玩家可操作。输入释放后才恢复，防止确认键同时触发攻击。 |
| 展示、份数、排序 | 展示该玩家持有的主动、被动与跟班；同 ID 合并并显示数量；临时份数单独标识。按获得顺序排列，显示图标、名字、数量、当前操作；合法性由调用功能决定。返回 ID 与对应份数类别，不把选择某一类偷换成删掉所有份数。 |
| 费用、取消、失败 | 选择器自身不扣费。确认时重新核对目标与调用条件，成功执行后由调用者扣费；取消、无目标和目标失效不执行操作。 |
| 中断和多人 | 换房、换层、死亡、退出游戏、调用者失去操作资格时取消会话。每位玩家独立选取，只接受本人控制器输入。界面会话不跨退出游戏保存。 |
| 界面风格 | 使用紧凑图标网格与选中框，沿用游戏 UI 的像素风格；过多目标时翻页，提示当前操作及确认／取消。 |

### 零分考卷

| 待定项 | 建议采用的规则 |
| --- | --- |
| 三层窗口、重叠、持有旧卷 | 使用滚动连续三层窗口；第 1～3 层成功后，第 2～4 层仍可成功。同一玩家每层最多生成一份，持有旧卷不阻止新卷。 |
| 头目后受伤的时点 | 前两层直到离层前的有效受伤都可计入。第三层只在清理头目房的结算时判断，当时不满足则本层不因之后受伤补发。 |
| 受伤次数、丢下、转交、多份 | 每份实际饰品各有五次机会；丢下再捡、转交和死亡复活都保留该份剩余次数。持有多份时，一次有效受伤同时消耗各份一次；耗尽的份数分别移除。获得一份新的实物才有新五次。 |
| 金色、妈妈的盒子、吞下 | 属性按照引擎实际饰品倍率增强，五次受伤耐久不加倍；吞下仍保留剩余次数并能在耗尽后移除对应效果。普通、金色和吞下后的份数分开记录，不能误删其他饰品。 |
| 进度、续局、沙漏、多人、多形态 | 获取进度与耐久均保存至续局；沙漏回退相应房间状态。连续受伤条件和生成奖励按玩家分别统计；同一玩家的不同形态共享该玩家的进度，合作玩家不共享。 |
| 图标 | 一张带醒目红色 0 分标记的旧考卷，沿用项目现有饰品像素风格。 |

### 回声宝宝

| 待定项 | 建议采用的规则 |
| --- | --- |
| 宝宝资格、多个跟班、特殊对象、自身 | 按实际配置的宝宝标签筛选，排除回声宝宝自身；一次拾取复制该道具对应的一组跟班，而不是仅复制组内第一只。技术上无法准确对应来源的特殊对象需明确诊断，不能凭变体猜测或宣称全部外部 Mod 都支持。 |
| 多份回声宝宝 | 自带回声宝宝数量随本道具份数增加；一次新宝宝拾取的额外复制组数及属性抽取仍各为一次，不因多份本道具倍增。 |
| 失去、重骰、死亡复活 | 已生成的复制宝宝与累计属性保留至本局结束；失去回声宝宝后不再触发新的奖励。失去原宝宝不删除已奖励的复制宝宝。死亡后在同一局复活保留既有奖励；连体沿用原生变身的保留规则。 |
| 续局、去重、沙漏 | 保存累计属性、复制记录与实际拾取实例；续局不补算；沙漏回退相应房间状态。不能只按道具 ID 去重，也不能用看到持有量增加代替新的实物拾取证据。 |
| 拉撒路与合作 | 拉撒路不同形态共享奖励与去重记录；自带与复制宝宝跟随当前形态。其他合作玩家分别拥有自己的奖励、跟班和去重记录。 |
| 射击、跟随、射程、增益和献祭 | 本体采用普通攻击跟班的跟随与按射击方向开火，基础每 28 帧、3 伤害；射程沿用鲍比弟弟的原生基准。BFFS、婴儿弯勺等原生跟班增益按其实际机制生效；额外复制宝宝不变成收藏品，献祭/移除要按实际来源精确处理，不补发不存在的道具收益。 |
| 图像 | 回声宝宝采用灰紫色半透明宝宝与回声轮廓；图标与跟班动画沿用项目现有像素风格，复制的其他宝宝保留它们本身的资源。 |
