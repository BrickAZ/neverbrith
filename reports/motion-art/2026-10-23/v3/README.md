# V3：原版以撒＋临时特效手臂

后续反馈：用户展示截图并要求取消附加手臂。本目录仅保留历史，当前评审改看[V4无附加手臂版](../v4/README.md)。

用户在2026-10-23明确指出，期待的是保留原版以撒、出招时附加一点特效手臂。V2重画全身人物的方向被否定。本轮重新生成的内容只有8种透明手臂／手掌，不再生成或使用新人物。

直接打开[七种招式预览](preview.html)，先看[原版主体／附加手臂对照](identity_comparison.png)。主体取自原版未修改PNG和原版ANM2正／侧／背面裁切；手臂是单独图层。对照图上方原生1x，下方准确4x最近邻放大。

## 上一版不满意原因

1. 主体选择错误：把招式识别度建立在新画的头、脸、躯干和腿上，改变了原版以撒的比例与辨识度。
2. 美术表达错误：肉身格斗姿势替代了用户期待的短时特效手臂，近景尤其容易显得像换角色。
3. 动作接触不足：应该由附加手臂承担推掌、上勾拳和抓握，并贴合波体／目标，而不是仅靠换一张全身姿势与人物位移。
4. 验收重点偏离：镜头数量、文件数量和资源检查不能弥补视觉主体错误。先看原生尺寸下是否还是原版以撒，再看拳、掌和抓握是否读得懂。

## 来源与检查

手臂通过内置imagegen重新生成，原始PNG以原字节保存在`source-images/effect_arms.png`；[提示词](generation-prompt.md)与[Alpha组件发现结果](generated-crops.json)保留。未使用Python重画或擦改PNG，脚本只做ANM2编排与离线合成。波体、火焰和声音沿用V2已交付资源；声音仍为日语，未重新提取或变更注册。

构建：`python reports/motion-art/2026-10-23/v3/build_previews.py`。专项检查：`python reports/motion-art/2026-10-23/v3/verify_package.py`。脚本复用V2镜头和效果编排，替换其人物姿势写入器；V2历史目录不覆盖。

[validation.json](validation.json)检查保存后的XML、素材SHA-256、原版人物裁切和固定比例、无重画全身图层、手臂保留于Effect、GIF时长与视频帧率、日语选择、范围基线。逐裁切三底色预览为`crops_checker.png`、`crops_white.png`、`crops_room.png`。实际命令及退出码记录在`checks.json`。

本轮是候选美术重新生成与独立ANM2预览，不表示观感已获用户接受，也未做Isaac内的真实渲染、角色服装组合或镜头验收。未写Lua，未改共享输入、攻击限制、正式注册、道具数值、池或存档。

最终构建与专项检查退出0：7份ANM2、14段动画、14个正常／慢放GIF，1776个人物图层关键帧按原版裁切／比例／色彩验证，39个实际裁切可读；8个范围基线文件不变。导航检查退出0，99个本地链接可解析。已查看主体对照、关键分镜和三底色裁切，用户观感仍待反馈。
