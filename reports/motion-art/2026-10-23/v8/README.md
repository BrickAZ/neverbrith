# V8：720镜头跟着动作走

历史版本。当前720已按完整卡普空普通SA3重做，请看[V9视频与官方同步对照](../v9/README.md)。V8其余三项保持并沿用至V9。

[打开当前预览](preview.html)，720已放在第一项。可直接看[日语视频](circle_720_jpn.mp4)、[GIF](circle_720.gif)、[三倍慢放](circle_720_slow.gif)或[完整分镜](circle_720_strip.png)。[V7／V8同步对照](circle_720_camera_compare.mp4)左侧为旧镜头，右侧为本轮候选，日语与总时长一致。

本轮调整720，其他三项原样复制。脸部特写改为短侧面构图，抓取、抱摔蓄势和起跳连续进行；镜头在接触、起跳、悬停、重摔等动作点切换。上升时跟拍并拉开，下坠时给重摔方向留空间；砸地短停后回弹，再收回房间。暗背景与黑边在拉远时渐退。

旧版呆板的主要来源是长正脸放大、站立摆姿势与跨镜头跳位。V8去掉了4.3倍单独正脸，所有近景保留人物和被抓目标；按实际轮廓计算构图边界，用偏心构图和平滑跟随代替反复居中。演员先完成世界坐标动作，镜头只变换一次，切镜时不把演员挪到新位置。

原版以撒头、脸、身体和腿保留，没有新增手臂或重画人物。720依旧单一版本，老桑仍用日语。保留390帧／30fps和原混音，台词、音高、播放顺序与原声素材未改。唯一波动、普通／两段OD升龙、360两档的3份ANM2与25个媒体文件和V7逐字节一致，其他波动候选没有恢复。

## 文件与检查

候选目录：`resources/gfx/Effects/MotionShowcase/v8/`。当前4份ANM2、12段动画、6种演出；媒体为12个GIF、6段单独视频、2段普通／OD对照及1段720新旧镜头对照。720仍含`Preview`／`Effect`，后者隐藏示范人物与目标。正式游戏镜头、玩家外观绑定和战斗逻辑尚未接入。

[camera-timeline.json](camera-timeline.json)记录每帧镜头与切镜点，[anchors.json](anchors.json)记录演员和构图范围，[manifest.json](manifest.json)记录素材及来源哈希。专项检查从保存后的XML验证裁切、角色原样、完整构图、切镜前后演员连续、缩放变化、四帧命中停顿、回房间的相机零位，以及其他三项的完整文件一致性；同时验证媒体帧数、时长、日语音轨和已删除候选未恢复。

实际命令、初次发现的收镜跳变及修正后退出码见[checks.json](checks.json)，最终结果见[validation.json](validation.json)。初次检查发现低通相机末帧未收敛到1倍；现已在收镜末段逐步取消滞后并精确归零。构建、媒体、资源和文档检查不能替代游戏内渲染或观感验收。

本轮仅交付离线ANM2镜头候选，没有修改Lua、输入、攻击限制、数值、道具池、正式注册或存档。
