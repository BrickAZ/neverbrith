# Debug Report Template

Use this structure when reporting a debug pass.

```markdown
## Debug Result

- Symptom:
- Likely surface:
- Static checks:
- Scripted tests:
- In-game checks:
- Root cause:
- Fix:
- Remaining risk:
```

If no fix was made, replace `Fix` with `Recommended next patch`.
