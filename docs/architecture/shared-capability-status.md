## 必须保留的语义差异

1. **身份**：逻辑玩家共享、身体背包、运行期 pointer+InitSeed、实物 token 是不同语义；记忆紊乱还有角色/伙伴持久身份与运行期重绑，不能统一为一个万能键。
2. **复制**：plain_data.CopyTree 供临时复制、回声宝宝、零分考卷、获取服务四处同合同实现；Blinky Core.Clone 拒绝非序列化叶值，记忆紊乱复制在 nil/非表及元表处理上不同，继续各自持有。不是所有递归复制都应替换。
3. **射速**：fire_rate 为非负增量及 0.0001 下界；零分 0.00001、回声 delay>-1 与5/s剩余额度、拳套 -.99 下界/力竭/奖励下限、七咒0.75倍率、直接减间隔或置零各属不同合同。
4. **控制**：本轮已实现三件实际 CanShoot 消费者的所有者句柄；选择器输入过滤、阿瓦达攻击接管、搓招抓取/pose租约、拳套移动/冻结旗标属于不同控制渠道，不能直接用射击权限服务替代。原目标第6.1的整轮组合证据仍按相互作用逐项关闭，不能把保留输入/抓取政策描述为 CanShoot 句柄尚未实现。
5. **取得与保存**：原生实际获取收据、狗粮库存/碰撞后的健康奖励、椰子前后伤害采样、流量即时消费是不同结算点；Blinky 储物不随共享沙漏回退，motion 的 SA/OD 快照与拳套瞬态取消也不同。
6. **伤害与随机**：真实扣血、命中尝试、HP变化观察、直接减血和击杀收据分开；查询不新增 RNG 消费，fallback数值化、取整、种子与遍历深度保留。

## 退出与整轮收尾

- 当前同合同公共实现均有实际消费者和 API 文档；旧算法退出/保留理由见相应清单。原根工厂、正式 Mod 门面与独立调用适配仍有兼容用途，不为完成计数强删。
