## 6. 确定性资源与生成边界

- 正常头发由 `tools\rebuild-dante-separated-hair.ps1` 手工定义八帧整体填色、计算外轮廓、
  短内部发束分界、断续高光和七级调色；不使用随机数、坐标取模或外部图片像素。
- 头发 PNG：512×64，SHA256
  `71E7E7D95ECFDFB10BAED7435E58CA29C5E63143117D9424F271F4973ABB5FFB`。
- 基础图 PNG：512×512，SHA256
  `3300A297BC7E39435C3672734EDBE6DF507D7673313D6DD0850E03FC8F37C8C8`。
- 六个普通基础头部格与官方模板逐像素相同；银发身份由独立 Costume 提供。
- 两个生成器连续运行得到相同哈希。
- 六个可见脸帧对基础头眼、泪线和嘴的受保护像素重叠均为 0；该检查使用真实 32×32
  头部裁切、Left 镜像和 Costume `+16,+16` Pivot 差值。
- Down/Right/Up/Left A/B 的垂直重心差为 0.809/1.000/1.227/1.000 像素；这些数值只防止
  两帧僵死或夸张弹跳，不能替代原生 1× 审美判断。
- 任何生成器返回尺寸、棋盘预览、搜索缩略图或第三方图集均不直接复制进正式资源。

## 7. Isaac 化保守补全与未采用素材

- 背向与严格侧向只延伸附件已证明的银发、酒红外套和黑色主体，不补画来源不明结构。
- 特殊动作沿用官方姿态、Pivot、脚底和动画时间，只重编码批准的大轮廓与色块。
- 未采用任何《鬼泣1—4》、动画、重制／重启、跨界／联动、同人或其他版本。
- 未采用聚合站、百科、论坛、社交媒体、Chusheng 美术或其他参考模组像素。
- 枪与剑不会生成攻击、Projectile、Laser、碰撞、音效、武器切换或任何战斗机制。
- 当前没有阻止本轮可撤销美术修复的 `TBD — user decision required`；严格游戏内视觉
  和用户审批属于验证状态，不是待猜测的设计决定。
