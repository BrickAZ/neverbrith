# 显式安装与既有顺序

本 Skill 发布分支没有引入新的安装事务库。模组装配仍以 [main.lua](../../main.lua) 的实际加载和登记位置为准，不能假定存在其他 checkout 中的 `feature_installation` 接口。

按[开发规范](../agent/development-conventions.md)整理 callback 时，原处理函数后紧邻原生绑定或显式安装方法，装配层在原位置调用；事件存在性守卫、循环、priority、filter、返回值及同事件下的登记顺序均保留。安装方法不默认幂等，重复调用会重复登记。

若目标 checkout 已有安装事务，应沿用其当前入口、失败回滚和实例所有权，不为了取得安装方法重新创建子模块。事务能恢复哪些副作用、失败后能否重试及卸载责任，应由该库随实现交付的说明定义，不能由 Skill 推断。
