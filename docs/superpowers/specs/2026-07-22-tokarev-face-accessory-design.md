# Tokarev 脸部挂饰设计

## 目标

在现有 Tokarev 斗篷挂饰内部增加一件可独立装卸的脸部挂饰，使游戏内形象从“穿斗篷的以撒”进一步变成 Tokarev，同时不替换基础玩家皮肤、不改写原版素材，也不把脸部直接合并进兜帽贴图。

## 已锁定决定

- 采用方案 A：完整深蓝内嵌面罩。
- 正面使用深蓝黑面部与两块宽大的青色眼片，不绘制嘴部。
- 左右侧面只显示朝向侧的一块主眼片，并保留少量远侧轮廓提示。
- 背面不显示脸部面罩，只保留现有兜帽。
- 脸部与 Tokarev 斗篷组成同一套“千变万化”样式，但资源和 Null Costume 保持独立。
- 不修改以撒基础身体或基础脸部贴图，不覆盖原版素材。

## 视觉设计

### 正面

- 面罩限定在兜帽开口内部，不扩张玩家头部外轮廓。
- 主体使用近黑藏青，内部最多两级蓝黑明暗，不使用纯黑填满整个面部。
- 两块青色眼片采用横向圆角楔形：外侧略高、内侧略低，形成 Tokarev 的慵懒眼神。
- 眼片占面罩面积的重点，但与深色外轮廓之间保留至少一像素安全边。
- 不绘制嘴、鼻孔、皮肤色或额外高光。

### 左右侧面

- 主眼片随朝向移动到可见侧，尺寸略窄于正面单眼片。
- 远侧只保留一小段青色或深色提示，避免侧面仍像正脸。
- 左右方向互为严格镜像，除非模板坐标合同要求独立微调。

### 背面

- `HeadUp` 对应区域保持完全透明，避免在兜帽背后出现眼睛。

## 像素与透明度约束

- 使用整数像素硬边，不做缩放抗锯齿、模糊、羽化或半透明描边。
- 新增可见像素必须属于目标 `head2` 裁切区域，不得跨入相邻方向帧。
- 透明区保持 `alpha=0`；导出前清理透明像素中的脏 RGB，避免采样时出现黑红杂边。
- 颜色控制为近黑藏青、两级蓝黑、主青色与少量亮青色；不引入红色轮廓。
- 游戏尺寸检查优先于放大预览，确保眼片不会糊成两块亮色噪点。

## 技术结构

- 新建独立脸部 ANM2 与 PNG，不改现有 `costume_tokarev_cloak.anm2`。
- 新脸部 ANM2 使用 `head2`，动画名与现有稳定面具模板一致。
- 在 `costumes2.xml` 中注册独立 `type="none"` Null Costume；具体本地 ID 在实现阶段按当前文件末尾顺延发现，不预先硬编码。
- “千变万化”的 `tokarev_cloak` 样式同时拥有现有 `accessory` 斗篷资源与新的 `face` 资源；应用、重抽和移除时分别管理两个 Costume ID。
- 任何其他样式不自动获得该脸部挂饰。

## 验收

- 静态：PNG 为预期画布与 RGBA；四方向裁切均在界内；`HeadUp` 无面部可见像素；透明区无非零 alpha；没有半透明边与红色污染。
- ANM2：引用正确 PNG，使用 `head2`，四个 `Head*` 动画存在且坐标/枢轴来自项目稳定模板。
- 注册：XML、Lua 路径与测试中的 Costume ID 查找一致；Tokarev 样式同时增加和移除斗篷、脸部两个挂饰。
- 游戏内：正面能在一眼内识别出深色面部与青色双眼；侧面只读出一只主眼；背面无眼睛；斗篷仍完整；换道具、重抽、换房和继续游戏后不残留、不丢失、不重复。
- 兼容性：允许其他高优先级道具外观正常覆盖或部分遮挡脸部，不通过修改基础皮肤强行压过全部道具。

## 非目标

- 不把 Tokarev 做成完整自定义角色。
- 不新增独立可拾取道具、属性、机制、图标或文本。
- 不保证所有原版道具都不遮挡面罩；本设计遵循原生 Costume 叠层行为。
