# Tokarev 斗篷挂饰设计

## 目标

为“千变万化”制作一套只改变玩家服装叠层的 Tokarev 斗篷候选素材。它不得替换基础玩家身体、脸部或完整玩家 ANM2，也不得覆盖原版 `c216` 素材。

## 已锁定决定

- 以后默认制作挂饰，不再制作完整角色皮肤。
- Tokarev 只提取斗篷，不加入枪械、苹果或其他人物元素。
- 技术结构参考原版 `216_ceremonialrobes.anm2`：`body0` 身体斗篷层加 `head4` 兜帽层。
- 第一版只生成候选 PNG，不修改 `content/costumes2.xml`、`main.lua` 或现有样式注册表。

## 方案比较

1. **c216 双层轮廓锁定重绘（采用）**：保留原版每格轮廓与透明度，只把外层改为近黑藏青、内衬与窄边改为青色。兼容性最高，也最容易检查脏边。
2. **仅 body0 斗篷**：完全不碰头部，但 Tokarev 的兜帽识别点会消失。
3. **原创扩张轮廓**：斗篷更像 Tokarev，但需要重新绘制每个方向和全部步行动画，第一版风险过高。

## 第一版美术约束

- 外层：近黑藏青，避免纯黑大色块。
- 阴影：两级蓝黑，不使用红黑边。
- 内衬和窄边：低面积青色，仅用于领口、内侧与动作折边。
- 可见色块必须保持原生硬边；alpha 与 c216 源图逐像素完全相等，不新增半透明像素。原版 head 已有的 `77/153` 阴影 alpha 必须原样保留，不得扩张或改写。
- 不改变 c216 原贴图的可见像素位置；第一版属于纯重绘/重配色候选。
