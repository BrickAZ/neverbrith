## 2. 已确认效果

### 2.1 自带回声宝宝与连体套装

- 拾取后生成一只“回声宝宝”跟班。
- 回声宝宝每 28 帧发射一颗灵体泪弹，每颗造成 3 点伤害。
- 获得该道具时直接获得『连体』套装。
- 以上攻击参数描述回声宝宝本体，不用于统一覆盖后续复制的其他宝宝。

### 2.2 复制新拾取的宝宝

每次符合条件地拾取一个宝宝道具：

1. 额外生成所拾取道具对应的宝宝，即复制刚捡到的宝宝，而不是增加一只回声宝宝，也不是随机选择其他宝宝。
2. 额外宝宝不计入道具栏；复制宝宝本身不等于再获得一份收藏品。
3. 同时进行一次属性奖励抽取，两个结果互斥：
   - 50% 的概率获得 +1.0 攻击力。
   - 50% 的概率获得 +0.5 攻速。

不可把两个 50% 实现成两次独立抽取，导致同时获得两项奖励或两项都没有。额外生成跟班的动作也不是新一次拾取，不应递归结算上述奖励。

### 2.3 攻速上限与累计

- 此处 +0.5 攻速按面板射速加成记录；这项加成不突破原版 5.0 上限。
- 即使当前已经达到 5.0，仍然可以抽到攻速奖励，且仍累计这次 +0.5；面板可以不变。
- 达到上限不重抽，不把攻速奖励改成攻击力，也不丢弃该次加成。
- 后续其他攻速加成变化时，已累计的这部分加成仍参与重新计算。
- 例如：当前攻速 4.8 时抽到攻速奖励，在没有其他突破上限效果的情况下，面板最多达到 5.0；当前为 5.0 时抽到奖励，面板保持 5.0，但奖励仍被记录。
- “不突破上限”约束本道具提供的这份加成，不应把其他道具合法突破上限后的射速强行压回 5.0。开发时须核对原版射速计算顺序及当前项目的属性处理方式。

## 3. 已确认的两个触发限制

这两个限制同时约束额外宝宝和随机属性奖励。

### 3.1 不追溯已有宝宝

获得回声宝宝时，不对之前已经拥有的宝宝道具补发复制宝宝或属性奖励；之后新拾取的宝宝道具才触发。

### 3.2 同一件道具不重复结算

同一件宝宝道具被放下再捡起，不会再次获得复制宝宝或属性奖励。

新获得的另一份同名宝宝道具仍可正常触发。因此，去重对象是同一件实际道具的重复拾取，不能简化为“每种道具 ID 整局只能触发一次”。具体身份追踪方式须在开发时调查引擎与项目实现，不在本记录中预设 API 或存储方案。

## 4. 后续开发验收例子

以下为待执行的验收用例，不代表已经测试通过。

| 场景 | 预期结果 |
| --- | --- |
| 先拥有一个鲍比弟弟，再获得回声宝宝 | 生成回声宝宝并获得连体；不因原有鲍比弟弟补发复制或属性奖励 |
| 此后新拾取另一件鲍比弟弟 | 额外生成一个鲍比弟弟，并抽取一次属性奖励 |
| 将已经触发过奖励的那件鲍比弟弟放下再捡起 | 不再次复制，也不再次增加属性 |
| 再新获得一份同名鲍比弟弟 | 这份新道具正常触发一次复制和一次属性奖励 |
| 生成上述额外宝宝 | 不增加收藏品数量，不再次触发拾取奖励 |
| 攻速 4.8 时抽到攻速奖励，无其他突破上限效果 | 记录 +0.5，面板最多达到 5.0 |
| 攻速已经 5.0 时抽到攻速奖励 | 记录 +0.5，面板可不变，不改发攻击力、不重抽 |
| 累计奖励后，其他攻速加成发生变化 | 已累计的攻速奖励继续参与计算 |
| 原有其他道具已合法突破射速上限 | 回声宝宝不得用全局强制限幅把该效果压回 5.0 |
