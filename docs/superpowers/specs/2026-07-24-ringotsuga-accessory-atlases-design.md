# RingoTsuga 三配饰实际图集设计

## 目标

把当前 `ringotsuga_apple_storyteller` 的完整玩家皮肤造型，重新表达为三张互相独立的透明硬像素 Costume 图集：

1. 完整包裹头部的苹果外壳；
2. 苹果内部的 Ringo 脸；
3. 深蓝连帽衫身体服装。

本阶段只生产 PNG、确定性生成器、静态视觉测试和组合预览，不修改 `main.lua`、`content/costumes2.xml`、现有 Ringo 完整皮肤 PNG/ANM2，也不创建或接入新的 Costume ANM2。

## 已批准造型

- 苹果必须完整包裹以撒头部，不是头顶小帽。
- 外壳包含红苹果轮廓、短棕色果梗和一片绿色叶子。
- 脸部独立，包含红色内脸、青色眼睛、深色瞳孔/上眼缘和小矩形嘴。
- 身体是紧凑的深蓝连帽衫，使用少量青色抽绳和袖口点缀。
- 采用原生低分辨率硬像素；只允许 alpha `0` 或 `255`，透明像素 RGB 必须为 `0,0,0`。
- 不允许抗锯齿、渐变、抖动、半透明阴影、脱离主体的黑红杂边或跨格像素。

## 图集映射

### 苹果头壳

路径：`resources/gfx/characters/costumes/costume_ringotsuga_apple_shell.png`

- 画布 `256x64`。
- 每格 `32x64`，方向顺序：Down `0..1`、Right `2..3`、Up `4..5`、Left `6..7`。
- 预期未来枢轴为项目已证明的 `XPivot=16, YPivot=44`。
- Down/Right/Left 外壳保留透明脸部开口；Up 为不透明苹果背面。

### Ringo 脸

路径：`resources/gfx/characters/costumes/costume_ringotsuga_face.png`

- 画布 `256x32`。
- 每格 `32x32`，方向顺序：Down `0..1`、Right `2..3`、Up `4..5`、Left `6..7`。
- 预期未来枢轴为项目已证明的 `XPivot=16, YPivot=28`。
- Up 两格保持完全透明，因为背面由苹果外壳负责。

### 深蓝连帽衫

路径：`resources/gfx/characters/costumes/costume_ringotsuga_hoodie.png`

- 画布 `256x256`。
- 每格 `32x32`。
- Right 使用 `(0..7, y=0)` 与 `(0..1, y=32)`；
- Down 使用 `(0..7, y=64)` 与 `(0..1, y=96)`；
- Left 使用 `(0..7, y=128)` 与 `(0..1, y=160)`；
- Up 使用 `(0..7, y=192)` 与 `(0..1, y=224)`。
- 预期未来枢轴为项目已证明的 `XPivot=16, YPivot=25`。
- 四个方向分别绘制，Up 不复用 Down 的青色抽绳正面。

## 调色与轮廓

- 苹果轮廓使用深栗色，不使用纯黑色随机光晕。
- 苹果主体采用暗红、中红、亮红三级平涂。
- 果梗使用深棕/棕，叶片使用深绿/绿/浅绿。
- 眼睛使用深青/亮青/青白。
- 连帽衫使用深海军蓝、海军蓝和亮蓝，青色只作为小面积识别点。
- 所有轮廓在原始尺寸保持一像素为主；透明区不保存脏 RGB。

## 验收

- 三张 PNG 尺寸、RGBA/alpha 合同和格子映射正确。
- 所有透明像素 RGB 为零。
- 无半透明像素。
- 可见像素只来自批准调色板。
- 头壳八格非空；脸部 Up 两格为空，其余六格非空；身体四方向各十格非空。
- Left/Right 方向在结构上镜像，叶子可保留同一植物生长侧而不强制镜像。
- 组合预览在游戏尺寸仍能辨认苹果头、青眼与深蓝连帽衫。
- 由于本阶段不创建 ANM2 或注册 Costume，不能声称已在游戏中加载。
