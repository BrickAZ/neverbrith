# 炸弹套装 / Bomb Suit

用户已批准本地开发。设计来自本任务对话中的逐项确认；自动检查不代表用户已试玩通过。

## 注册与提示

- 被动道具，品质 3。
- 宝箱房 `treasure`、贪婪宝箱房 `greedTreasure`、炸弹乞丐 `bombBum`，各权重 1。
- 中文拾取文本：`上吧，你现在是真正的炸弹人了!`
- 英文拾取文本：`Go! You're a real Bomberman now!`
- 本地 XML ID 63；运行 ID 使用名称查找，不写死。

## 效果

持有者实际受到非卖血伤害并失去红心、魂心或骨心容器后进入炸弹状态。首次伤害正常结算；假伤害、盾挡和被取消的伤害不启动。

状态持续 90 个游戏逻辑帧（3 秒），暂停不推进。期间移速增加 0.5，不能射击，并免疫卖血以外的伤害。状态结束时在玩家当前位置产生一次普通玩家炸弹规则的爆炸，继承爆炸时玩家拥有的炸弹强化；该次爆炸及能证明来源的派生效果不会伤害持有者。它不消耗炸弹资源。

卖血仅指献血机（原版实体 6.2）、IV 袋的专用伤害旗标、恶魔乞丐（原版实体 6.5）。这些伤害不能启动状态，状态中仍正常扣血。剃刀、血之权利、锋利插头不列入卖血排除。

## 状态边界

- 多份不叠加；状态中再次受伤或卖血不刷新倒计时。
- 普通换房、换层继续计时，爆炸位置取结束时的位置。
- 死亡、失去最后一份道具、退出游戏、继续存档、卸载本 Mod 时取消状态。
- 发光沙漏回溯取消状态，回溯后不还原旧倒计时。
- 状态仅保存在运行内存中，不进入 Mod 存档。
- 每位玩家单独计时与恢复属性；自伤保护仅归属于该持有者的这次爆炸。

## 视觉与声音

使用独立 32×32 RGBA 彩色道具图标和本地 ID 63 的 16×16 原生菜单/死亡手绘格。状态中头顶显示引线火花，玩家短时闪烁，并播放逐渐加快的提示声，末尾半秒加强闪动。
