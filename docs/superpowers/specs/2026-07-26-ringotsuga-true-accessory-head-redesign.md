# RingoTsuga 真挂饰头部重制设计

## 目标

把 RingoTsuga 当前近似“整头换皮”的苹果头与脸部，重制为能与原版以撒身体、脸部及其他道具自然叠加的独立挂饰。

## 设计边界

- 保留现有三个 Null Costume 槽位与注册关系：`head4` 苹果帽、`head2` 脸部特征、`body0` 上衣。
- 本次只重画苹果帽与脸部特征；浅灰白上衣保持不变。
- 不替换原版角色身体或基础脸部，不抑制其他道具外观。
- 图集尺寸、裁切尺寸、枢轴和资源路径保持不变。

## 苹果帽

- 苹果不再形成 32 像素宽的圆形头壳，而是只覆盖头顶和后脑上缘。
- 每帧左右至少保留 3 像素透明边，主体宽度不超过 26 像素。
- 红色苹果轮廓只延伸到原版脸部上缘；正面和侧面的中央脸区保持开放。
- 保留小号枝梗、叶片和少量奶油色额发，作为 RingoTsuga 的识别锚点。
- 两相帧分别绘制轻微上下起伏，不再复制同一帧。

## 脸部特征

- 删除全部肤色脸板，只绘制眼框、浅色眼面、绿色瞳孔、极少量青色泪痕与嘴部标记。
- 正面允许两个眼部组件和一个嘴部组件；侧面允许眼部和嘴部组件。
- 特征图层保持小面积、硬像素和二值透明，原版以撒脸型必须仍然可见。
- 第二相与苹果帽同步起伏，避免脸部在苹果壳内独立滑动。

## 验收标准

- 所有透明像素的 RGB 为零，不含半透明、纯黑杂边或调色板外像素。
- 苹果帽不接触帧边、不覆盖大面积脸区、不形成整头圆壳。
- 脸部图集不含任何肤色像素。
- 正面、侧面、背面以及两相帧均有真实差异。
- ANM2 的头部两层统一使用相同的垂直位置。
- 现有注册、上衣、千变万化逻辑与其他道具外观兼容性不变。
