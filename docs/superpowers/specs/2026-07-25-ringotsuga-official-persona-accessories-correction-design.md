# RingoTsuga 官方拟人形象三挂饰纠正设计

## 纠正原因

此前把 Ringo 误读成“完整红苹果吉祥物”，因此 `head4` 画成了包围整张脸的苹果头套。重新核对 RingoTsuga 官方频道公开视频后，主形象实际是苹果拟人角色：肤色脸、橘红苹果发型、浅奶黄色侧发束、绿色大眼、大绿叶和宽松灰白上衣。

用户已明确授权本次由 Codex 自主决定全部非删除事项，并要求不中途询问。因此本设计记录即为本轮锁定方向。

## 锁定结构

### `head4`：苹果发型

- 文件名 `costume_ringotsuga_apple_shell.png` 为兼容保留，但不再画苹果壳。
- 正面为橘红发帽和两侧发束，中央大面积开放给肤色脸。
- 两侧加入向外翘的浅奶黄色侧发束，这是 Ringo 的高优先级识别特征。
- 顶部保留短棕梗和向左上展开的大绿叶。
- 侧面为橘红后发、前额发束、单侧黄色发束和脸部开口。
- 背面为完整橘红发团、梗叶和少量暗面，不出现脸部。

### `head2`：肤色脸和绿色眼睛

- 正面为肤色脸平面，不再使用红色内脸。
- 两只大眼使用奶油色眼白、绿色虹膜和深色瞳孔。
- 眉毛和小嘴使用深棕灰；眼睛轻微不对称，保留 Ringo 的手绘表情。
- 以撒语境只加入窄而短的青色泪痕，不覆盖绿色虹膜。
- 侧面只显示朝镜头的一只眼及短泪痕。
- Up 两格保持完全透明，由 `head4` 负责背面。

### `body0`：官方浅色服装

- 宽松灰白上衣，体积明显小于头部。
- 正面胸口用极简深色像素暗示 `APPLE` 字样，不追求逐字可读。
- 下摆加入绿色短裤/腰线色块。
- 手臂使用肤色，鞋或最下方脚部使用深棕灰。
- 四方向十相位保持原有坐标、枢轴、脚底接触与左右镜像。

## 不变合同

- 不改三个 ANM2、Costume ID、priority、Lua 三槽位和生命周期。
- 不改 PNG 画布尺寸、格子位置、方向顺序、枢轴或脚底接触点。
- 不覆盖原版玩家图集。
- 不生成额外肖像或菜单素材。

## 完成判定

自动测试必须证明画布、格子、alpha、调色板、连通性、左右镜像和 ANM2 接入合同未退化。最终在原始游戏尺寸自问：“如果 Ringo 来到《以撒》，会是这样吗？”只有在橘红发型、黄色侧发、绿色眼睛、大叶和灰白上衣均能被快速读出，且不再像苹果头套时，才接受输出。
