## 1. 玩家承诺与范围

玩家持有本系列道具后，全部原生攻击与替代武器攻击均被禁用，只保留本系列道具招式的攻击。所有方向指令统一用射击方向键，WASD只移动。未搓招时射击键确定朝向，按住主动键后普通指令沿用起手前朝向，不用指令箭头反过来旋转基准；波动仍按该次射击单击的方向发起。

通用输入模块覆盖波动单击、双波动双击、反波动（214）、升龙（623）、后蓄前、360 与 720。波动不再要求 236，双波动不再要求 236236，也不是 236236 后再补一个 6。反波动 214 继续作为独立指令保留，不自动混入单击波动道具。

输入模块负责识别，不决定各招式的伤害、资源、目标、演出，也不把所有招式放进同一个道具。实现入口见[通用输入实施计划](../plans/2026-10-22-motion-input-system.md)。

[桑吉尔夫双道具设计](2026-10-21-zangief-grapple-pair-design.md)继续维护两个独立道具、抓取与演出、720 独立三格气槽等规则；本文件是共享输入规则的维护位置。

## 3. 相对方向与起手时刻

按住主动键进入预备状态后，普通搓招以首个有效射击方向采样开始计时，方向基准取预备前最后明确朝向；波动类以第一次新的射击方向按下事件起手并按该方向发射。主动键之前的历史不补入；射击键旧长按不算一次新的波动点击。

未按住主动键时，射击方向键继续更新朝向意图。当前唯一方向优先，否则保留最近明确朝向；从未射击时采用当前头朝向。普通搓招期间冻结这项更新，箭头只形成相对方向序列，松开主动键后恢复更新；同次采样无法排序不随机换向。

锁定的是识别坐标基准，不推导出冻结玩家或强制实际头部持续朝向。原生攻击禁用按第 6 节的持有规则独立生效；普通移动与各招式演出中的移动限制仍由道具设计决定。

以先点右射击键`→`再松开、随后按住主动键为例，前方为屏幕右方：

| 数字方向 | 相对含义 | 射击方向键 |
| --- | --- | --- |
| 6 | 前 | → |
| 4 | 后 | ← |
| 8 | 上 | ↑ |
| 2 | 下 | ↓ |
| 3 | 下前 | ↓+→ |
| 1 | 下后 | ↓+← |

因此`↓、↓+←、←`为反摇214。单波动仍直接按射击键一次，不改回236。WASD不参与方向合成，不能抵消箭头输入。

蓄力采用“后蓄前”：朝右起手时，按住主动键并用`←`蓄力0.5秒，离开后方向后0.2秒内转前自动完成。1／4／7都算后蓄，6／3／9都可完成；当前没有注册这件道具，不因此恢复已删除候选。

其他射击朝向使用同样的相对坐标旋转解释。采用射击输入意图作为朝向来源，不根据追踪、反弹等效果改变后的泪弹飞行方向回推朝向。具体输入读取接口与采样时序由实施时核对。

## 4. 键盘输入示例

### 4.1 波动与双波动的单击／双击

- 波动：按住主动键，按一下 `→`，向右发起波动；其他三个射击方向同理。
- 双波动：按住主动键，`→ 按下 → 松开 → 再按下`，第二次按下时自动发起双波动。两次按下之间必须能辨认出松开，不要求再按确认键。
- 双波动沿用已确认的 1.2 秒总窗口，从第一次新按下到第二次新按下计时；不自行改成更短的双击窗口。
- 两击必须是同一射击方向。第二击换方向时，原尝试失效，该新方向按下可作为新尝试的第一击，并重新锁定朝向。
- 普通波动道具不会等待第二击；双波动道具第一击不会先释放普通波动。
- 第一击后一直按住方向键不产生第二击；松键本身不触发。双击内部的松开不要求额外停顿 0.1 秒。

### 4.2 其他指令的宽松按法

以下以起手射击朝右为例，均须按住主动键：

| 指令 | 接受的键盘序列 |
| --- | --- |
| 反波动 214 | `↓、↓+←、←`或`↓、←`；也接受`↓+←、←` |
| 升龙 623 | `→、↓、↓+→`；也接受`→、↓、→`（626）、`↓+→、↓、↓+→`（323） |
| 后蓄前 | `←`／`↓+←`／`↑+←`蓄满0.5秒，离开后方向后0.2秒内输入`→`／`↓+→`／`↑+→` |

单个斜方向不能重复充当多个输入步骤；升龙保留三段有序方向变化，不把仅有“前→下”算成完整指令。

### 4.3 360 与 720

以下例子均以按住主动键、起手射击朝右为前提。

| 指令 | 直接按主方向 | 自然滚键示例 |
| --- | --- | --- |
| 360 顺时针 | `→、↓、←、↑` | `→、→+↓、↓、↓+←、←、←+↑、↑` |
| 360 逆时针 | `→、↑、←、↓` | `→、→+↑、↑、↑+←、←、←+↓、↓` |
| 720 顺时针 | `→、↓、←、↑、→、↓、←、↑` | 两轮间可自然经过相邻斜方向 |
| 720 逆时针 | `→、↑、←、↓、→、↑、←、↓` | 两轮间可自然经过相邻斜方向 |

`↑、→、↓、←`等其他起始方向同样有效；`→、←、↓、↑`乱序不成立，不能只看四个方向都出现过。

这里的 360、720 是招式指令名称。宽松判定分别允许约 270° 的四主方向覆盖和约 630° 的连续八主方向覆盖；不额外要求严格转满几何角度或补按起始方向。

## 5. 时间与容错

| 项目 | 已确认窗口 | 项目 30Hz 逻辑计时换算 |
| --- | --- | --- |
| 波动单击 | 新射击按下事件即完成，不等待第二击 | 不再使用旧 236 的 0.6 秒手势窗口 |
| 双波动双击 | 1.2 秒 | 36 个逻辑帧的经过时间 |
| 反波动 214 | 0.6 秒 | 18 个逻辑帧的经过时间 |
| 升龙 623／626／323 | 0.6 秒 | 18 个逻辑帧的经过时间 |
| 后方向蓄力 | 0.5 秒 | 15 个逻辑帧的经过时间 |
| 蓄力完成后转前 | 0.2 秒 | 6 个逻辑帧的经过时间 |
| 360 | 0.8 秒 | 24 个逻辑帧的经过时间 |
| 720 | 1.5 秒 | 45 个逻辑帧的经过时间 |

计时从首个有效方向输入开始；判断完成时与起手时的时间差，不把采样数量误当成经过帧数。容错期间总窗口仍然计时，不因重复方向、短暂回中或回弹延长。

- 不强制采齐八个扇区，允许缺少斜向采样。
- 按住同一方向的连续采样只代表一个方向，不要求玩家每一步维持固定帧数。
- 普通搓招连续回中不超过 0.2 秒时保留进度；超过后结束本次尝试。双击间的射击松开按其 1.2 秒专用窗口处理，不套用普通方向指令的0.2秒回中截止。
- 回到上一步方向不超过 2 个逻辑帧（2/30 秒）可视为手指回弹，不立即清空，也不增长进度；持续倒转或其他乱序使当前尝试失效，从最近合法的新起手重新匹配。不得任意删掉错误方向来拼成成功。
- 容错不能取消主方向的旋转顺序要求，不能允许任意乱按凑齐方向。
- 相反移动方向重叠时，识别器采用后按者；同次采样无法确定先后时该轴按中立处理，不制造方向。这条策略不改写原版移动。
- 蓄力中回中不超过 0.1 秒时保留蓄力但暂停增长，超过后重新蓄；蓄满后的释放窗口另按 0.2 秒处理。未按主动键时不积攒蓄力。
- 不得沿用旧计划的“一跳段或反向就全部重置”。输入变化独立采集，同一帧重复轮询不能被计成多次方向变化或多次点击。

## 6. 识别结果、道具条件与反馈

### 6.1 指令归属、重新监听与短缓存

识别成功即自动发起招式，不等待松键，也不追加出招键。每个道具只启用自身的一种指令；识别库的其他能力不得抢先释放。一次完成立即消耗输入历史，不能因重复扫描而发出多个释放事件。

普通搓招完成后，主动键可继续按住；射击方向键全部回中连续 0.1 秒即可重新监听，也可松开再按主动键重新起手。失败或超时不要求重按主动键，从下一次新的有效方向变化起手，不借用已过期历史。波动类使用射击按下事件重新起手，前一次长按必须先松开，不要求方向键额外回中来产生新的射击点击。

仅因收招暂时不可执行时，完整指令最多缓存 0.2 秒且只有一条；保持主动键、恢复可执行条件后释放一次，不能借此取消原本不可取消的动作。已有待发指令时不再排入后续指令。松开主动键、换房、死亡或切换道具清空缓存，超时作废，不自动重试。

输入匹配成功与招式最终生效分开记录。例如，720 仍受双道具设计中已确认的三格气量条件约束。资源不足、目标不符时立即反馈，不缓存等待气满或敌人靠近；失败是否扣资源、空放效果仍由各道具规则决定。

720 第一轮只累计；双波动第一击只累计。波动与双波动、360 与 720 分属各自道具，不以全局短招识别抢占当前道具。

### 6.2 持有时只保留道具招式攻击

持有任一本轮搓招系列道具，就禁用该玩家的全部原生攻击输出，包括普通泪弹以及硫磺火、科技、妈刀、骨棒等全部替代武器，只保留本系列道具招式的攻击。不以是否按住主动键、是否正在演出或是否当前选中为开关。书包中未选中的相关道具仍属于持有。同系列同时持有多件时，失去其中一件不能解除禁用；失去最后一件时解除本系统的限制。

这一限制只属于持有者，不影响未持有的合作玩家。不能因斗气拳套提供了输入参考，就自动把它或其他既有道具加入本系列的限制触发名单。

禁用的是攻击输出，射击方向键仍可更新朝向、供锁定基准使用，并驱动波动单击／双波动双击。不得通过把所有射击输入返回零来实现限制。解除时仅移除本系统限制，不能强制开启被其他机制禁用的射击。

替代武器范围已经全部确认，不能再标为待定，也不能只禁泪弹实体而漏掉射线、刀、骨棒等攻击。持续按射、蓄力、松键释放及持续命中的路径都必须遵守同一限制，不经普通射击入口的持有者非招式攻击也不能成为绕过路径。

允许的攻击必须能明确归属到本系列道具招式及其派生攻击；不能把“攻击属于持有者”本身当成放行依据，也不能把所有玩家来源伤害一并取消而误伤招式。具体来源标记、传播与引擎拦截入口由实施阶段发现并验证，不能用全房实体删除代替归属判断。

### 6.3 反馈

显示最近输入、当前锁定前方与识别进度，并区分“输入未完成”“输入正确，暂存中”“输入正确，条件不足”。双波动显示一击／两击进度，长按不重复闪动。具体显示位置、图形与资源不在本轮指定。
