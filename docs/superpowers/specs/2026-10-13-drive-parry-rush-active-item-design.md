## 1. 玩法定位与规则归属

拿到本道具后，玩家可以通过后撤方向输入进行普通防御，通过按住主动键进行蓝防，并在蓝防中输入移动方向立即发动绿冲。三种行为使用同一条斗气槽；斗气归零会进入力竭，削弱射速与伤害，直到斗气回满。

| 项目 | 已确认规则 |

| 同一局重新获得 | 沿用该玩家保存的斗气与力竭状态，不重新填满 |
| 状态归属 | 斗气与力竭属于本局该玩家，玩家之间独立 |
| 多份本道具 | 同一玩家共用一条斗气槽，防御和恢复速度不叠加 |

## 3. 持有范围与独立充能

### 3.1 持有范围

普通方向防御和斗气恢复随持有生效，蓝防与绿冲需要实际使用本道具。

| 道具位置或操作 | 是否算持有 | 生效范围 |
| --- | --- | --- |
| 当前选中的主动栏 | 是 | 普通防御、斗气恢复、蓝防与绿冲 |
| 书包中未选中的副主动栏 | 是 | 普通防御与斗气恢复；切换到本道具后才能新发动蓝防、绿冲 |
| 口袋主动栏 | 是 | 普通防御与斗气恢复；通过对应使用键发动蓝防、绿冲 |
| 切换书包中的主动道具 | 仍然持有 | 不触发离身处理；绿冲期间切换不结束绿冲 |
| 被换到地上、移除，或重骰后身上已没有本道具 | 否 | 执行第13节的离身规则 |

### 3.2 与普通主动充能分开

| 普通主动系统的效果 | 对本道具的影响 |
| --- | --- |
| 清理房间产生的普通主动充能 | 不恢复斗气；期间的击杀仍各回1格 |
| 电池拾取、其他普通充能效果 | 不恢复斗气，也不能直接解除力竭 |
| 角色给普通主动充能所用的额外资源 | 发动本道具时不消耗，也不转换为斗气 |
| 汽车电池等重复发动效果 | 同一次操作只发动一次蓝防或绿冲，支付一次对应费用 |
| 同时持有多份本道具 | 共用玩家的一条斗气槽，恢复与防御不叠加 |

本道具能否发动只由斗气、当前动作状态和对应输入决定。书包里的其他主动继续使用原本充能资源。

## 4. 防御范围与有效命中结算

### 4.1 防御范围

| 伤害类型 | 普通方向防御 | 蓝防 |
| --- | --- | --- |
| 有可判定来向的普通飞行攻击 | 可以，需输入正确方向 | 可以 |
| 其他有来源、方向可判定，且不属于下列排除项的伤害 | 可以，需输入正确方向 | 可以 |
| 接触伤害 | 不可以 | 可以 |
| 激光 | 不可以 | 可以 |
| 地板伤害 | 不可以 | 可以 |
| 无来源伤害 | 不可以 | 可以 |
| 炸弹伤害 | 可以，但必须有来源、方向可判定且输入正确 | 不可以 |
| 必须支付的主动生命代价 | 不可以 | 不可以 |

“接触、激光、地板、无来源不能防御”限定普通方向防御。蓝防采用除炸弹伤害和必须支付的生命代价外均可防御的规则。本文的炸弹排除项不能未经确认扩大成所有形式的爆炸伤害。

### 4.2 结算优先级

已有无敌时间挡掉的攻击不产生本次防御结算，不能重复扣费或获取奖励。必须支付的生命代价按第12节处理，不进入本道具的防御收益流程。

其余需要结算的有效命中依次检查：

1. 完美蓝防。
2. 普通蓝防。
3. 普通方向防御。
4. 其他护盾。
5. 实际受伤。

一次有效命中只结算其中一项。蓝防与正确后撤输入同时满足时，只结算蓝防，不再另扣普通防御的斗气；蓝防自身的启动费和持续消耗照常计算。

某次攻击不能蓝防时，继续检查它是否允许普通方向防御，且方向是否正确。两种防御都不成立，再交给其他护盾。

### 4.3 防御与受伤无敌时间

成功防御不减少生命值，不算受伤。设计目标是避免触发受伤充能、掉落、增益、惩罚及受伤记录等效果，同时给予这类正常受伤对应的原生无敌时间。

无敌时间内的后续无效命中，不重复扣斗气、回气或授予完美奖励。持续攻击超过无敌时间后仍然存在，则按下一次正常有效命中重新结算。采用原生有效命中的节奏，不用“同一个攻击实体永远只能收费一次”替代。

原生伤害接口的取消时点、无敌时间单位以及对其他受伤效果的隔离，需要开发时核实，不能把本条设计目标当作已经实机验证的结论。

## 5. 普通方向防御

持有本道具即自动启用，无需按主动键。

1. 启动为0f，输入正确后撤方向即可防御。
2. 飞行攻击以命中前的实际飞行方向判断。例如弹幕从左向右飞，按右为正确方向；弯曲、回旋弹幕看命中前的实际方向。
3. 其他可防御的有来源伤害，以伤害来源的位置判断，向远离来源的方向输入。
4. 方向宽容为±45°，包含边界。攻击从正左方打来，右、右上、右下可以防，上、下、左不可以防。
5. 只看移动输入，不要求发生实际位移。贴墙也能防，完全没有移动方向输入则不能普通防御。
6. 成功防御按正常应受伤害扣斗气：半心＝1格，一心＝2格，依此换算。
7. 绿冲双倍伤害不参与防御扣费。绿冲中防住原本半心的攻击，仍扣1格。
8. 普通防御必须等本次斗气扣费结算完成后才能重新射击，没有另设固定射击后摇。
9. 蓝防的12f松手后摇期间仍可普通防御；移动输入只提供防御方向，不产生主动行走。已力竭时普通防御失去保护。

**最后一击**：尚未力竭时，即使剩余斗气不足以支付整次防御，也允许防住最后一击。剩余斗气扣到0，立即进入力竭，并保留本次防御的原生无敌时间。

例：剩0.5格，下一击需要1格，仍防住该次攻击，扣到0并力竭，不把不足部分改为生命损失。

## 6. 蓝防与松手后摇

按住本道具对应主动使用键进入蓝防。蓝防没有额外启动等待，期间不能移动、不能射击。有效移动方向输入会直接转入绿冲，不产生蓝防行走。

- 启动支付0.5格，持续每秒消耗0.3格。
- 成功启动后的前3f为完美蓝防窗口。
- 普通蓝防每次有效防御回复0.5格。
- 完美蓝防一次性回满6格，并授予第8节的射击奖励。
- 回满不是锁定满槽，之后继续按当前动作规则耗气。
- 已有射击奖励不会阻止后续完美蓝防继续回满斗气。
- 未成功招架时，主动松手退出至少持续6f，然后进入12f松手后摇；成功招架后的退出例外见6.1节，不能一律追加12f。
- 6f只限制未满足成功退出条件的主动松手退出；第6.1节成功退出窗口内松手或成功转入绿冲均可提前结束，斗气耗尽也立即结束防护。
- 蓝防和后摇期间不能射击。蓝防期间不能移动，方向输入直接申请绿冲；12f后摇期间不能移动，只允许普通方向防御，方向输入不会发动绿冲。
- 后摇期间继续读取移动方向用于普通防御，但不把该输入转换为行走位移；防御仍使用第5节的方向、范围、费用与无敌时间规则，不变成全向蓝防。
- 后摇期间成功普通防御、完成斗气扣费，不会提前解除尚未结束的12f操作限制。
- 按用户“只可以防御”的最新要求，后摇期间其他主动战斗操作也不执行，包括投弹、使用卡牌／药丸／其他主动与切换书包。这个限制只针对12f后摇，不扩大到绿冲的第7.6节。
- 12f后摇期间不能发动蓝防或绿冲，发动输入不缓存。后摇结束后需重新按下主动键。

2026-10-14用户将原“17f后摇、可移动”改为“12f、不能移动和射击、不能再次蓝防或绿冲、只可以防御”。用户句中的“不能设计”按上下文理解为“不能射击”。随后用户确认3f撤光、6f收招、3f复原，并要求制作脚下灰蓝残弧；具体表现和资源状态见第20节。需要执行后摇时，12f从实际退出蓝防开始计算；未成功招架的提前松手仍先满足最短6f。光效分段不另加操作锁定时间。

启动前斗气恰好0.5格等归零边界，按第11节处理，不能因“0f启动”在已经力竭后补结算完美蓝防。

### 6.1 成功招架后的后摇取消（2026-10-14补充）

用户指出普通Parry和Perfect Parry成功会取消蓝防后摇，并进一步确认“仅紧接成功的退出免后摇”。随后回复“可以”，采用统一6f成功退出窗口、成功退出可越过最短6f、不额外增加成功硬直的方案。此前把所有主动松手一律写成12f的表述不完整，由本条修正。

- 普通蓝防或完美蓝防实际成功结算后，从成功结算帧起提供6f免后摇退出窗口，包含成功帧。若成功帧记作S，有效范围为S至S＋5，S＋6起过期。
- 在窗口内松手直接退出蓝防，不追加空挥时的12f松手后摇，也不额外增加成功硬直；即使本次蓝防尚未达到6f最短持续，也允许提前结束。
- 成功后仍继续按住主动键则继续蓝防，原有不能射击和持续耗气规则保留；一次成功不产生本次长按永久免后摇资格。
- 成功退出机会结束后，继续空持再松手仍执行12f后摇。
- 再次有效蓝防／完美蓝防成功，从新成功帧重新提供6f退出窗口；原生无敌时间内的无效命中不生成成功，也不刷新窗口。射击奖励仍独立沿用第8.3节最早一次去重规则。
- 已进入12f后摇时没有蓝防判定；其中的普通方向防御不是Parry成功，仍不提前解除后摇。
- 满足免后摇退出条件时，不播放12f收招姿态和灰蓝残弧。普通蓝防6f／完美蓝防10f成功反馈只是视觉效果，不能自动当作操作硬直或退出窗口。
- 强制力竭退出与绿冲失败付费等原有特殊分支暂沿用第11节，不因本条自动获得免后摇待遇。

**已确认的以撒适配**：上述6f窗口是本项目采用的操作宽容，不是街霸原版统一的固定6f规则。正常退出后恢复普通移动与射击；获得成功或退出本身不强制发射，射击奖励的首次实际发射起算规则不变。

后续验收应覆盖：成功窗口首帧与末帧松手均免后摇，过期首帧松手进入12f；蓝防前3f内完美成功后松手可在未满最短6f时退出；空挥提前松手仍先满足6f；持续按住直到窗口过期不永久免后摇；新的有效成功刷新退出窗口但不刷新已有射击奖励；无敌期间无效命中不刷新；后摇中普通方向防御不提前解除操作限制。以上为验收目标，尚未接入或实测。

## 7. 绿冲

### 7.1 蓝防转入绿冲

2026-10-15用户明确纠正为：蓝防期间不能移动、不能射击，一旦按移动方向就绿冲。此决定替代旧版“蓝防可走动、8f同向双击绿冲”。

正在蓝防时，一个有效移动方向输入立即发动绿冲，允许斜向；不要求双击或方向松开。按住方向再进入蓝防、或主动键与方向同时输入，也会直接申请绿冲。摇杆沿用已有0.2长度死区，低于死区保持原地蓝防；初始角度使用真实输入向量，不量化为八向。无方向或相反方向完全抵消时继续蓝防。一次动作只付费／触发一次，持续按住方向不会连续重开。

有效方向输入且费用足够时直接转入绿冲，不必等蓝防满6f。蓝防持续耗气立即停止，额外支付0.5格，不经过12f松手后摇，之前支付的蓝防费用不退。

单看发动与维持成本：

**蓝防接绿冲成本**：0.5格蓝防启动费＋蓝防维持时间×0.3格／秒＋0.5格绿冲费。

这不包含途中回气或额外普通防御扣费，不能写成一套固定只消耗1格。

没有有效方向输入时原地维持蓝防，只发生原本的持续消耗，不额外扣绿冲费用。方向输入有效但费用不足时，斗气清零并力竭，绿冲不发动，蓝防结束并进入后摇。

### 7.3 方向与通行

#### 7.3.1 已确认边界

- 发动输入决定初始方向；冲刺过程中可以随移动输入平滑转向。这是2026-10-13用户后续明确确认的新规则，替代“全程锁定方向、沿直线冲刺”。移动方向与光效旋转不受八方向动画名称限制。
- 实际位移经过4f后，输入反方向可以刹车；启动停顿不计入这4f。
- 绿冲速度与最大距离独立于角色移速，不被移速道具或减速效果改变。
- 沿用角色原有通行能力，遇到角色不能通过的障碍立即停止。
- 刹车、碰撞或其他原因结束时，剩余距离作废，不储存到下一次。

#### 7.3.2 已确认控制细则（2026-10-14）

用户于2026-10-14确认：“平滑转向、反向刹车和距离规则就按这套来，更新设计文档，先不要写代码。”以下整套规则已获采用，作为正式设计；v3演示中的预设轨迹仍仅展示动画，不是输入控制或路程实现。

**平滑转向**：

- 有效移动输入指定目标方向，实际冲刺方向每逻辑帧沿较短方向最多转15°，即450°／秒；不足15°时直接对齐目标，避免来回越过目标。刹车方向按下文优先识别。
- 维持同一目标输入时，45°转弯用3f＝0.10秒，90°转弯用6f＝0.20秒。转弯全程保持260÷18的固定冲刺速度，转向本身不额外收费。
- 键盘可以只有八个输入方向，但冲刺朝向经过中间角度逐步转过去；手柄使用原生有效移动输入的方向。有效输入的强弱不改变冲刺速度或15°／f上限。
- 没有有效方向输入时，保持当前冲刺方向和速度，直至路程耗尽或其他已确认结束条件成立。
- 5f启动停顿不推进转向，也不累计位移帧数。停顿结束后，从发动方向开始，根据当时仍有效的输入处理第一个移动帧；不会补做停顿期间的转向。
- 可以连续改变目标方向绕弯，只要每次输入不落入下文刹车范围且还有剩余路程。累计转角不另设总上限；直接按反向则按刹车规则处理。

**反向刹车**：

- 参照当前实际冲刺方向，在应用本帧转向之前比较移动输入。两者夹角达到135°至180°（包含135°）视作刹车输入，即当前后方±45°范围。
- 夹角小于135°用于平滑转向。因此正侧方90°可以转弯；以当前向右冲为例，左、左上、左下属于刹车输入。
- 已完成的实际位移不足4f时，刹车输入暂不改变冲刺方向，也不提前停止。仍可通过其他方向正常转向。这里只限制本次冲刺控制，不吞掉原始移动输入，普通防御仍按第5节判断。
- 完成第4个移动帧后，只要此刻仍有刹车输入，立即结束绿冲，不再走第5步。若提前短按反向、在门槛前已经松开，则不缓存成之后的自动刹车。
- 同一次操作判定中，刹车优先于转向和下一步绿冲位移。这不改变原有伤害、防御及强制中断的结算规则。
- 刹车直接恢复普通状态。5f射击门槛只限制仍在进行的绿冲；已经刹停后按普通射击规则处理，包括等待当次普通防御扣费完成。刹车本身不发射、不消耗射击奖励，也不增加后摇。

**转弯后的路程预算**：

- 绿冲发动时按初始方向一次确定总路程，沿用第7.2节的标准单房间中心到边缘标尺。水平260、垂直140、45°斜向140×√2≈197.99。途中转向不重新取标尺。
- 沿实际冲刺路径累计已走距离，每走一段扣一段；不能只看当前位置与出发点的直线距离。连续转弯、绕回起点或重复方向输入均不刷新本次预算、位移计时或刹车／射击门槛。
- 水平起冲后转向上方，整段弯曲路径仍最多260；垂直起冲后转向水平方向，整段仍最多140。这也意味着水平起冲后的纵向位移不另外受140上限约束；本方案把“半房间”定义为初始方向给定的总路程。
- 例如水平起冲已经走80，再开始拐弯，剩余就是180；完成转弯本身走过的距离也从这180中扣除。掉头绕回也不会返还路程。
- 转弯保持固定速度，所以同一初始方向、未被其他条件提前结束的绿冲，直线与弯线耗时一致：水平预算18个移动帧，垂直10个，45°斜向14个。最后一帧只走剩余距离。
- 碰撞仍按实际路线与角色原有通行能力判断，首次碰到不能通过的障碍就停止，不能用转向绕过已经发生的阻挡。剩余距离作废。

## 8. 射击奖励

绿冲与完美蓝防授予同一类射击奖励，采用同一套最早一次去重规则。

**视觉提示决定（2026-10-14）**：用户明确射击奖励不需要额外视觉提示。不制作奖励专用图标、倒计时、角色光环或获得／取消提示动画；已有武器原生的蓄力和射击表现照常。此决定只涉及表现，以下一次满蓄力、3秒射速、去重与力竭取消规则不变。

### 8.1 射速与起算点

- 射速提高到4.0，不是增加4.0。
- 当前射速达到或超过4.0时，射速部分没有额外收益，不降低原有射速。
- 射速奖励持续3秒。
- 非蓄力攻击从首次实际射击开始3秒。
- 蓄力攻击先获得一次满蓄力，发射该次攻击时才开始3秒。
- 尚未触发射击时3秒尚未开始。

### 8.2 一次满蓄力

| 当前攻击状态 | 处理 |
| --- | --- |
| 尚未开始或部分蓄力 | 直接把当前这次攻击推进到满蓄力 |
| 已经满蓄力 | 保持满蓄力，首次发射后进入3秒射速奖励 |
| 一次满蓄力产生多枚弹幕、多方向攻击或一轮连发 | 整次按正常满蓄力结果完成，合计消耗一次奖励 |
| 蓄力后发射持续攻击 | 完成启动蓄力，持续时间沿用武器原有规则 |
| 当前攻击没有蓄力过程 | 首次实际射击直接开始3秒射速奖励 |

满蓄力填满当前这次攻击，不额外储存一发备用满蓄力。伤害、弹数、大小、射程等沿用该武器正常满蓄力结果。

发射沿用武器原有操作，获得奖励本身不强制自动攻击。蓝防、后摇和绿冲尚未允许射击的阶段仍不能发射。

3秒从该次攻击开始发射时计算，不等连发或持续攻击全部结束。后续弹幕、连发或持续部分不能重启计时。

### 8.3 重复触发

1. 已有等待中或生效中的射击奖励时，保留最早那次。
2. 后续触发不叠加、不排队、不重置3秒，也不额外赠送满蓄力。
3. 仅对射击奖励去重。后续完美蓝防仍回满斗气，普通蓝防和击杀回气仍正常结算。
4. 原奖励结束后可以获得下一次新奖励。
5. 力竭立即取消尚未使用或仍在持续的射击奖励。

### 8.4 武器与射击模式切换

包括拾取道具导致攻击方式改变的情况。射速奖励随玩家保留等待状态或剩余时间，满蓄力不因切换重新赠送。

| 切换时状态 | 处理 |
| --- | --- |
| 满蓄力尚未发射 | 蓄力是否保留沿用原有切换规则，不给新武器重新补满 |
| 原本非蓄力，随后换成蓄力武器 | 不额外送满蓄力；正常蓄力并发射后开始3秒 |
| 等待首次射击 | 继续等待，切换本身不开始计时，下一次实际发射才开始3秒 |
| 3秒已经开始 | 继续剩余时间，不刷新，不再次赠送满蓄力 |

如果原生切换会清除蓄力，获赠满蓄力随之失去；尚未开始的3秒射速奖励仍保留，等待下一次实际发射。

- 最多6格，溢出不储存。
- 命中敌人不回气。
- 道具离身时执行第13节的冻结规则，不能继续通过时间或击杀恢复。

## 11. 力竭与斗气归零边界

### 11.1 力竭效果与解除

斗气归零立即力竭：

- 射速×0.75，攻击伤害×0.75，立即生效。
- 普通方向防御失去保护，后撤输入仍会正常受伤。
- 不能新发动蓝防或绿冲。
- 取消尚未使用的赠送满蓄力及等待中、生效中的射速奖励。
- 其他护盾继续按原规则生效。
- 斗气恢复到满6格才解除，部分恢复不解除。
- 恢复途径为已确认的自然恢复、行走和击杀；不是固定20秒倒计时。
- 离身不能洗掉力竭，见第13节。

### 11.2 费用边界

| 情况 | 结果 |
| --- | --- |
| 尚未力竭，普通防御所需斗气超过剩余值 | 最后一击仍防住，扣到0并力竭，保留本次防御的无敌时间 |
| 普通状态发动蓝防，斗气不足0.5格 | 清零并力竭；不发动蓝防，不产生松手后摇 |
| 普通状态发动蓝防，恰好0.5格 | 支付后归零并力竭；不形成有效蓝防或完美窗口，不产生松手后摇 |
| 蓝防已成功启动，之后斗气耗尽 | 立即结束防护，进入12f后摇，即使未满6f |
| 蓝防期间尝试绿冲，费用不足0.5格 | 清零并力竭；绿冲不发动，蓝防结束并进入后摇 |
| 成功支付绿冲费用后恰好归零 | 立即力竭并取消射击奖励，仍允许本次已付费绿冲继续，不进入蓝防后摇 |

高于0.5格才能真正启动蓝防。已付费绿冲允许完成，但其力竭修正立即生效，之后不能发动新的蓝防或绿冲。已进入力竭后不能再通过受到攻击触发完美蓝防回满。

## 12. 生命代价与普通受伤的边界

本道具不能免除支付生命换资源、奖励或属性的费用。

| 事件 | 处理 |
| --- | --- |
| 敌人攻击、普通环境伤害、自身炸弹伤害 | 通常防御流程；绿冲中真正受伤则双倍并中断 |
| 献血、恶魔乞丐、献祭、刺箱、支付生命换资源或属性的主动效果 | 按原价结算，不能蓝防或普通防御；绿冲中不翻倍，不因支付本身中断 |
| 消耗心之容器的交易 | 原交易规则，不受绿冲伤害倍率影响 |
| 普通地刺、诅咒房门 | 环境伤害 |
| 献祭房的献祭刺 | 生命代价 |

生命代价不改扣斗气，不产生蓝防回气、完美蓝防或射击奖励。交易与其他原有效果沿游戏规则。付费效果若同时传送或强制接管位移，仍执行该效果本身的正常结果。

本条不能被改写为“任意实际扣血都触发绿冲双倍”：主动生命代价已经明确是例外。

## 13. 动作期间锁定道具与正常离身

### 13.1 锁定期间

采用用户最终决定：以下状态不能主动把本道具换到地上或丢弃。

- 蓝防期间。
- 绿冲启动停顿期间。
- 绿冲位移期间。
- 12f松手后摇期间。

会换走本道具的操作不执行，待动作与后摇结束后再正常换取。书包切换不让本道具离身，在蓝防／绿冲期间仍允许，且不打断绿冲；12f后摇期间按第6节“只可以防御”不执行书包切换。拾取其他不会换走本道具的道具照常。

单独力竭或射击奖励等待／生效不锁定道具。只要上述动作结束，就可以正常换走。

锁定规则针对已确认的主动换走与丢弃操作，不能据此自行增加未确认的全局重骰免疫或特殊联动。

### 13.2 正常离身

- 普通方向防御失效，不能再发动蓝防或绿冲。
- 自然恢复、行走恢复、击杀回气全部暂停，斗气数值冻结。
- 等待中与生效中的射击奖励立即清除，拿回不补发。
- 已有力竭与射速、伤害惩罚持续保持，不能通过换走清除。
- 拿回后从保存斗气继续恢复，力竭仍需回满6格才解除。
- 已获得的正常无敌时间按原时长自然结束。

不采用先前“动作中离身后逐项终止蓝防／绿冲、重算或保留后摇”的方案，不能把被撤回的方案重新作为已确认规则。

## 14. 保存与读档

斗气与力竭按用户确认的“随玩家保存”执行。同一局重新拿回不回满，也不清除力竭。

对蓝防、绿冲、后摇与射击奖励不新增专门的读档续接、进度恢复、补发或补偿方案，沿用游戏正常流程。不特意恢复动作方向、剩余距离、剩余动作帧、赠送满蓄力、等待状态或剩余3秒奖励，也不因为读档刷新奖励。

“不做特殊处理”不能被重新解释成必须保存全部临时状态，也不授权添加另一套强制清空全部原生状态的读档机制。
