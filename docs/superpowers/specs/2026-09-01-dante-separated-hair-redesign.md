# Dante 独立头发层重设计

## 状态

本设计已由用户在 2026-09-01 以“你改吧”批准。它修正此前将普通移动头发直接画进
`character_dante.png` 六个 32×32 头部格的失败路线。

## 失败归因

没有外部素材误导实现。用户提供的《鬼泣5》但丁参考图清楚展示了银白色中长分层发、
不规则分缝、额前与两侧独立发束。失败来自实现者自己编写的生成器和测试：

- 生成器用连续水平填充段构造发帽，再用坐标取模制造亮点；
- 测试只统计银色像素、轻微左右不对称和裁切合法性；
- 512×512 覆盖率与绿色测试被错误当成审美质量；
- 六个 32×32 基础头部格被错误当成必须容纳完整中长发的唯一载体。

因此旧结果虽然技术上可加载，却形成了高填充率、缺少负空间和分束结构的灰色头盔。

## 视觉权威与参考边界

- 唯一角色造型权威：用户附件以及同一标准造型的《鬼泣5》官方素材。
- 绝对禁止：《鬼泣1—4》、动画、重启／重制、跨界、同人和其他版本。
- `chusheng_3529211857` 只读用于确认 Isaac 技术载体与像素工艺量级；不复制其角色
  设计、发型轮廓、兔耳、调色板、帧像素或美术语义。

## 载体设计

### 正常移动

- `character_dante.png` 继续是 512×512 玩家基础皮肤，负责脸、身体、深红外套与特殊
  动作基底。
- 六个普通方向头部格恢复为官方 Isaac 头部几何，不再烘焙银发。
- 银发改为独立 `type="none"` Null Costume：
  `costume_dante_hair.anm2` + `costumes/costume_dante_hair.png`。
- PNG 为 512×64，按 Down A/B、Right A/B、Up A/B、Left A/B 排列八个 64×64 帧。
- ANM2 使用项目已验证的 `HeadDown/HeadRight/HeadUp/HeadLeft`、`XPivot=32`、
  `YPivot=44`、`YPosition=-5` 合同。
- 左右方向分别绘制，不从同一个侧面简单镜像。

### 特殊动作

拾取、受伤、特殊状态等由 512×512 基础图集真实消费的头部区域继续保留烘焙头发。
这些区域不得回退为无发 Isaac，也不得把独立 Costume 的 64×64 画布直接缩放粘贴。

## 发型语言

必须保留：

- 银白／冷灰色中长发；
- 不规则偏中分，而非齐刘海或圆形帽檐；
- 前额有分离的斜向发束；
- 两侧有长度不一、向下收尖的鬓发；
- 后脑有分层、收尖的外轮廓；
- 高光沿发束方向组织，不使用坐标取模噪点。

必须拒绝：

- 连续实心圆顶、整齐齐边、碗盖或头盔轮廓；
- 额头和脸周围没有透明负空间；
- 左右方向像素完全镜像；
- 只有四个平涂色且没有发流分区；
- 兔耳、角、发饰或 Chusheng/明日方舟角色语义。

## 生命周期

- 运行时身份通过 `Isaac.GetPlayerTypeByName("Dante", false)` 解析，不硬编码 PlayerType。
- Costume ID 通过真实 ANM2 路径解析。
- 每个实际回调玩家独立判断；非 Dante 永远不获得 Costume。
- 玩家初始化与游戏开始时同步，以覆盖新局、continue 和已存在玩家。
- 不使用每帧或每房间重复 `AddNullCostume`。
- 该装饰完全由玩家类型重建，不保存到 SaveData，不引入玩法状态。

## 验收

- 静态：XML、ANM2、PNG、八帧裁切、路径、二进制 Alpha、生命周期测试通过。
- 几何：每帧均在 64×64 内，左右不同，脸区保留透明负空间，拒绝高密度闭壳。
- 视觉：必须查看原始 1×、4× 最近邻和与基础头／身体合成的方向接触表。
- 游戏内：角色选择、单人、continue、两名 Dante、Dante+非 Dante、死亡复活和普通
  道具 Costume 叠层仍需真实游戏验证；静态通过不能替代游戏内通过。
- 用户视觉批准在用户查看新证据或游戏画面前保持 pending。
