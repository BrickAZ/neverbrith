## 2. 已确认的属性效果

持有饰品时提供以下加成：

| 属性 | 效果 |
| --- | --- |
| 攻击 | +5 |
| 攻速 | +5，可以突破常规攻速上限 |
| 射程 | +5 |
| 移速 | 不增加 |

- 用户已将最初的四项加成修正为不增加移速、剩下三项各加 5。
- 三项均为数值加成，不得擅自改成 +5% 或其他数值。
- 攻速加成表达射速增加，不得误实现为增加攻击间隔；该项加成明确允许突破常规上限。
- “全属性上升”是已提供的描述文案，不构成额外增加幸运、弹速或其他属性的授权。

## 3. 已确认的获取条件

从第 `n` 层的第一个房间（初始房间）开始统计：

1. 第 `n`、`n+1`、`n+2` 层，每层都需要至少发生一次有效受伤。
2. 有效受伤按原版 A+／满分考卷的受伤判定认定。
3. 清理第 `n+2` 层的头目房时，若三层分别满足受伤条件，则生成零分考卷。

该条件要求连续三层分别受伤，不是三层内合计受伤三次，也不是只在头目房内受伤。用户要求层数与最终头目房结算这一框架对应满分考卷，受伤要求改为每层有有效受伤。

### 3.1 允许重复生成

- 用户已明确：允许在同一局内重复生成零分考卷。
- 不得实现为每局最多生成一次。
- “允许重复生成”尚未规定三层窗口是否可以重叠、生成后从哪一层开始下一轮统计，或持有旧考卷时是否仍生成新考卷；这些边界保留在第 6 节。

## 4. 已确认的受伤移除规则

- 持有零分考卷后，累计受到五次有效伤害时，移除该饰品。
- 第 1～4 次有效受伤时保留饰品，第 5 次有效受伤时移除，并失去该饰品提供的属性加成。
- 此处统计受伤次数，不是损失的心数或伤害量；获取前为满足三层条件而发生的受伤不预先消耗饰品次数。
- 受伤口径沿用用户指定的原版 A+ 判定。开发时须核对原版对自伤、被护盾挡下的受击、被取消的伤害等情况的实际处理，不得把所有伤害回调或扣血事件直接当作有效受伤。

## 5. 后续开发验收例子

以下为待执行的验收用例，不代表已经测试通过。

| 场景 | 预期结果 |
| --- | --- |
| 获得一份普通零分考卷 | 攻击 +5、攻速 +5、射程 +5，移速不增加 |
| 原有攻速已达到常规上限，再获得饰品 | 仍获得可突破上限的 +5 攻速效果 |
| 连续三层每层至少一次有效受伤，清理第三层头目房 | 生成零分考卷 |
| 第一层受伤三次，后两层没有有效受伤 | 不满足三层分别受伤的生成条件 |
| 三层中有一层只有原版 A+ 不计入的受伤事件 | 该层不能据此算作已满足有效受伤条件 |
| 已生成过一份，之后再次满足已明确的完整生成条件 | 允许再次生成，不能被每局一次限制拦截；具体窗口待第 6 节确认 |
| 拾取后累计有效受伤 1～4 次 | 保留饰品及其属性效果 |
| 拾取后发生第 5 次有效受伤 | 移除饰品及其对应属性加成 |
| 一次有效受伤损失不同数量的生命值 | 均按一次受伤计算，不按心数扣除次数 |
| 持有期间发生原版 A+ 不计入的受伤事件 | 不消耗五次受伤计数 |

## 6. 开发前仍需明确的设计边界

以下均为 **TBD — user decision required**。本次仅归档，不要求现在继续讨论；后续开发前确认，不得擅自补成已批准规则。

- **重复生成与窗口结算**：三层窗口是否可重叠（例如第 1～3 层成功后，第 2～4 层是否也可成功），或生成后重新累计三层；持有旧考卷时是否仍可生成；前两层在清理头目房后、离层前才发生的受伤是否计入该轮。未确认前不能确定重复掉落的频率和完整结算时点。
- **受伤次数的归属与生命周期**：丢下再捡起、交给另一角色、死亡或复活后，剩余次数如何保留；存读档及发光沙漏回退时，获取进度、已生成记录和受伤次数如何恢复。未确认前不能选择通过换装重置次数或其他恢复规则。
