# 桑吉尔夫摔技双道具实施计划

**目标**：依据[设计文档](../specs/2026-10-21-zangief-grapple-pair-design.md)，在 neverbrith 中实现两个独立道具：360 近身指令投与 720 三气大招。设计中的待定项必须先经用户确认，实现不得代为决定。

**2026-10-22 输入修订**：共享输入按[设计规格](../specs/2026-10-22-motion-input-system-design.md)与[独立实施计划](2026-10-22-motion-input-system.md)执行。时间、容错、朝向兜底、重新监听、短缓存，以及持有期间禁用全部原生／替代武器攻击、只保留道具招式攻击均已确认，不再作为输入设计阻塞。波动／双波动已改用射击方向键单击／双击，不改变本计划两个摔技的 WASD 摇圈。此处同步计划，不表示任何实现项已完成。

**结构**：

- 复用通用计划的 `motion_input_core.lua` 与 `motion_input.lua`，不另建一套 `grapple_input` 判定；每个摔技只注册自己的 profile。其他指令的效果与载体不在双道具计划内顺带决定。
- 道具 A 模块负责预备、抓取、旋转、砸地；优先验证“逐帧写目标位置”的抓取方案，失败则退到视觉替身方案。
- 道具 B 模块负责 3 格气槽、摇两圈判定与演出阶段机。
- 视觉、音效、HUD 各自独立，不在玩法模块里直接画东西。
- 仅气槽等确认为存档范围的量进入玩家存档；动作状态属于运行时。

**技术**：Isaac Repentance + 当前 REPENTOGON；Lua 5.4 与 PowerShell 7 检查；项目现有 XML、本地 ID 锁定表、生成器与验证器。
