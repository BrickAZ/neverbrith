## Global Constraints

- 360 0.8 秒，720 1.5 秒；四主方向一轮／连续两轮，不要求补回起点；允许顺逆、不同起点及省略斜向。
- 波动使用射击方向键一次新按下；双波动使用同方向两次独立按下，间隔不超过 1.2 秒。不是 WASD 前键，不是 236／236236。
- 反波动与升龙窗口各 0.6 秒；升龙接受 623／626／323。后蓄前为 0.5 秒蓄力、0.2 秒转前有效期。
- 普通输入中立保留 0.2 秒，回弹容许 2 个 30Hz 逻辑帧；蓄力中立保留 0.1 秒且暂停增长。
- 普通搓招完成后 射击方向键回中 0.1 秒重新监听；波动类依靠射击按下边沿，不套用 射击方向键回中条件。仅收招可缓存一条 0.2 秒指令。
- 第一次有效输入锁定射击输入朝向；原生攻击禁用时仍能读射击键。当前朝向→最近明确朝向→从未射击时的当前头朝向；不用移动朝向兜底。
- 持有任一本系列道具即禁用该玩家全部原生攻击，包括普通泪弹、硫磺火、科技、妈刀、骨棒等全部替代武器，只保留道具招式攻击；书包未选中仍算，失去最后一件才解除本系统限制，不能覆盖其他系统的射击限制。
- 替代武器禁用范围已确认，不再等待用户选择；各道具身份／数值／资源仍按规格第 7 节处理。
- 保留现有工作区改动；本计划不授权提交、推送或发布。

## Review Focus

1. 禁用全部原生攻击不能吞掉射击方向键，也不能误拦截道具招式；射线、刀与骨棒等非泪弹形态不得漏放。任务 2、3 验证。
2. 主动键之前的旧长按、同帧重复轮询、按键松开不能被计为第二击。任务 1、3 验证。
3. 波动单击与双波动双击是本轮替代规则；不能仍要求 236236，不能让双波动第一击释放单波动。任务 1、3 验证。
4. 中立／回弹容错不延长总窗口，也不能把乱序变成绕圈；蓄力不能累加任意零碎后退。任务 1 验证。
5. 多件持有、主动栏切换、其他系统禁射与队友必须各自隔离；解除不强制 `SetCanShoot(true)`。任务 2、3 验证。

## 文件与接口

| 文件 | 职责 |
| --- | --- |
| 新建 `motion_input_core.lua` | 无引擎对象的输入、识别与事件状态机 |
| 新建 `motion_input_shooting.lua` | 全部原生／替代武器攻击限制、招式来源放行、所有权与解除 |
| 新建 `motion_input.lua` | 玩家／主动栏适配、原始采样、注册分发与诊断数据 |
| 修改 `main.lua` | 增加单一模块接入，不搬动既有道具代码 |
| 新建 `tests/motion_input_core_test.lua` | 确认值、按键序列、边界、缓存与去重 |
| 新建 `tests/motion_input_shooting_test.lua` | 各武器与触发路径禁用、招式攻击保留、持有组合与解除隔离 |
| 新建 `tests/motion_input_behavior_test.lua` | 回调适配、双人、主动栏及执行回调 |

纯核心接口：

- `Core.New(baseline) -> state`：建立当前按键基线，初次读取不把已按住的射击键当成新点击。
- `Core.Step(state, sample) -> events`：推进一次实际采样，返回零个或多个诊断事件，每次完成最多一个 `execute`。
- `Core.Reset(state, baseline, reason)`：清理未完成指令、缓存与完成历史，并重新建立按键基线。
- `sample` 字段：`time`（暂停不增长的游戏时间，秒）、`sequence`（递增采样号）、`activeHeld`、`moveMask`、`shootMask`、`headFacing`、`profile`、`availability`。
- `moveMask`／`shootMask` 各自使用四位：左 1、右 2、上 4、下 8；相同采样中无法排序的新相反键按规格中立，不能伪造先后。`headFacing` 为 `left/right/up/down`。
- `profile` 为 `wave_tap`、`double_wave_tap`、`reverse_qcf`、`dp`、`charge_back_forward`、`circle_360`、`circle_720` 或 `nil`；每个注册道具只选一种。
- `availability` 为 `ready/recovery/resource/target`：只在 `recovery` 完整匹配时建立短缓存，其余失败不等待未来条件。
- 事件字段：`kind`（`execute/pending/failure/progress`）、`profile`、`facing`、`serial`、`reason`。`serial` 标识一次独立完成，重复读取不能生成新序号。

引擎服务接口：

- `include("motion_input")(mod, context) -> service`。
- `service:RegisterOwner(key, binding)`：`binding` 包含引擎运行时 `collectibleId`、唯一 `profile`、`has(player) -> boolean`、`availability(player) -> status`、`execute(player, command) -> {ok, reason}`。
- 注册名单同时定义触发攻击限制的本系列归属；不把“所有主动道具”或参考用斗气拳套自动加入。
- `Shooting.New(context) -> gate`、`gate:Update(player, ownedKeys)`、`gate:ReleasePlayer(player)`：依据本系统所有权施加／解除全部原生与替代武器攻击限制，保留可确认来源的道具招式攻击。
- 未批准或未注册的道具不编造 ID；可先用注入式绑定与模拟执行器验证共享模块，真实效果由各道具计划接入。
