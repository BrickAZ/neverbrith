# 招式多余硬直与恢复段控制修复

用户反馈720、普通升龙、OD升龙存在无敌且不能移动的多余硬直；OD规则已再次明确为起手到第二段结束无敌，收招可受伤。

1. 已核对的实现问题：720在释放目标289帧以后仍按完整394帧会话锁移动和免敌人伤害，留下约3.5秒站立锁定；升龙每个新命中都给同一会话追加停表，命中数量／到达时机改变整招实际锁定时长；升龙末次落地后空站的视觉恢复段也在重复覆盖真实位置。
2. 升龙取消逻辑停表，保留白拳、闪白和撞击声音；总30／50逻辑帧、伤害窗口、OD保护0–32、冷却不变。升空和OD两段衔接继续强制左右移动，最后一次落地后恢复WASD并停止覆盖原生玩家姿态，收招时间和单条短缓存保留。
3. 720在既有释放289帧结束战斗会话，同时交还移动、攻击监听和免伤；剩余V9帧以独立FX恢复尾段播放到394，不复制或摆布玩家，也不重复绘制已释放目标。新招可覆盖纯FX尾段；中断／换房／掉道具仍清理。
4. 没有来源证据时不归因原生道具举手动画，不用StopExtraAnimation或修改全局ControlsCooldown掩盖问题。原生用例额外记录该状态，避免把诊断自动输入等同于键盘行为。
5. 先写失败测试，验证多目标不延长升龙、落地后可移动且可受伤、720放开目标即解除保护／占用、纯FX尾段无角色姿态及NPC副本并自然结束。补跑本机隐藏引擎，只通过回调控制自己的测试进程，不接管桌面键鼠。

控制权由motion_combat.lua拥有，恢复尾段由motion_presentation.lua拥有；数值纯核心、输入核心、已确认源资源、池／品质不变。证据目录reports/motion-items/2026-10-25/recovery-control-v1。
