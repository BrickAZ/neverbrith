# 原版街霸6 SA条接入计划

**目标**：以本机街霸6原始SA HUD贴图、UV、布局和关键帧替换临时字符气条，接入积攒、满气闪光与消耗动画；不改变气量／OD／战斗规则、品质或池，不操作桌面键鼠。

**资源用途**：屏幕HUD，玩家各自拥有；Lua Sprite／ANM2载体。只替换SA显示，不替换人物、攻击、图标或其他原生HUD。原版数字、边框、底图和发光来自本机pak；颜色／布局／动画来自默认`ui30012.gui.530035`，数据可追溯。

**显示合同**：按原作采用0–3级数字和单条当前格进度；能量仍是既有0–90，每30一格。满90显示3和满条，开启循环闪光。显示动画只读实际气量，禁止通过动画结算消耗。持有本系列时显示，主玩家固定屏幕下方，合作玩家独立位置与状态；HUD隐藏／菜单不显示，暂停冻结视觉时钟；换房／继续／沙漏只重建显示，不触发虚假消耗。

1. 只读提取默认HUD的原始GUI/UV/TEX，校验TEX原始尺寸、RGBA Alpha及裁切。保存原文件哈希、映射和源关键帧。
2. 构建ANM2及贴图；数字升级、13帧FULL、25帧LOOP、5帧FADE_OUT保留原作时间基准（SF6 60Hz→Isaac30Hz）。以撒运行时的进度插值与消耗残影使用现有能量变化，不改变战斗。
3. 先失败测试再接入`motion_sa_hud.lua`；覆盖积攒、跨格、满气、消耗、退款、暂停、隐藏、重复Render、玩家隔离和清理。战斗模块仅提供只读气量和生命周期，旧字符SA条删除；OD倒计时和输入反馈继续各自显示。
4. 后台真实游戏验证实际伤害回气、满条闪光、720真实扣气及消耗动画、退款及退出；只对自有隐藏新测试局注入Lua输入，沿用精确状态备份恢复。不操作桌面键鼠。
5. 行为／资源／注册保存边界／统一Lua检查，检查来源与透明背景预览，交付实机与原始日志；不把离线预览当成游戏通过。

资源、脚本与证据：`reports/motion-sa-hud/2026-10-25/v1/`。开发直接在用户安装目录，保留已有未提交工作和before快照，不提交／推送。
