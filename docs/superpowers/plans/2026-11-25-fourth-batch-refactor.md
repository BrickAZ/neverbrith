四件已有独立入口。本次整理小皮鞋入口内仍交织的奖励取得、表现和热度状态依赖，不重复搬运其他道具。

| 所有者 | 本批职责 |
| --- | --- |
| little_leather_shoes/init.lua | 敌人死亡链、返场、房间/楼层流量、延迟清房及组装；保持事件登记顺序 |
| little_leather_shoes/rules.lua | 原返场概率、流量累计与档位纯计算，供玩法和 HUD 使用 |
| little_leather_shoes/rewards.lua | 奖励底座、二选一、取得确认、消费与效果派发；调用三件奖励的正式接口 |
| little_leather_shoes/presentation.lua | HUD、连线、拾取动画与完成通知；奖励发放由 rewards 执行 |
| traffic_unboxing.lua / traffic_exposure.lua | 保留原宝箱和当前房间池奖励规则，不合并不同随机/回退政策 |
| traffic_heat.lua | 永久层数与独立的临时刷新队列生命周期；显式读取原逻辑时钟 |
| little_leather_shoes/runtime_views.lua | 有限字段视图，兼容原 LittleLeatherShoesState 平面字段；每组仅可访问自己的字段 |

旧平面状态仍是公开兼容表。视图不改变字段名、表替换时点或旧引用语义；不把整个小皮鞋状态交给奖励、表现或热度。GetFrame/GetHudState 等查询不推进状态。
